## 方法

- 形态：API 级直测 · 单发单轮（`maxRounds = 1`）——用例提示 + 变体载荷（`tools`）→ 核 provider 路径 `chat` → 首个响应；判定面 = **首个工具调用** `{name, arguments}`。工具不真执行、题面路径为假想路径（无文件系统——判定只看参数成形）。
- 变体构造法：V0 = 产品面实面逐字（`builtinTools` × `toOpenAISchema`，含能力位 `read_image`）· V1 = 5 档枚举块（`read` / `grep` / `bash` / `git` / `edit`）+ V0 文本逐字 + `edit.edits[].*` 7 项参数描述 · V2 = 路由句（首行 → 首个句末符 → 120 字符硬截 `…`）+ 实面 schema 逐字。产品描述文本零改（变体只在探针载荷内构造）。
- 三轴判据：① 选择命中 = 首调 == 期望（期望无调用 ⇒ 无调用为命中）；② schema 合法 = `called` ∧ 全部调用可解析为 JSON 对象 ∧ 合该工具 `parameters`（射程 `type` / `required` / `enum` / `items` / `minimum` / `maximum`；载荷外工具名 ⇒ 否 + `offPayload` 单列）；③ 参数语义正确 = 轴① ∧ 逐例谓词。
- 分母：`n` = 有效 run（`terminal ∉ {error, skipped}`）；轴① 分母 = `n`；轴② / 轴③ 分母 = `n −` 期望无调用 run 数（其轴值为 `null`——不入分子与分母，`perfect` 同）；无调用 run 逐轴按轴表判并单列 `noCall`；接口错 / 空响应 run（`error`）无判定素材 ⇒ 三轴记 `null`（不入分母）。
- 成本式：（prompt − cached）× input + cached × cachedInput + completion × output（单价 = `bench/prices.json` 单源；缺价 / 缺 usage ⇒ `null`——**不按字符估 token**）。
- 已知偏差指针：逐条见《局限声明》（§11.10 ①–⑥）。
- 版本轴：本面自带 `TOOL_PROBE_VERSION`（= 1）；V0 载荷（产品面实面）不入本轴，由 `payloadDigest` 锚记；与 QA 套件 `SUITE_VERSION` / `PROBE_VERSION` 无关轴。

## 局限声明

- ① system 面 = 仅 `SYSTEM_BASE` 一行（真实会话另有人格 / 纪律槽 + 项目 AGENTS.md）——**绝对值不可外推**；变体间可比性不受影响。
- ② 载荷面 = `builtinTools` 静态表 + 能力位 `read_image`；**不含**实例绑定族（memory / `code_search` / `doc_search` / `repo_outline` / `settings` / `peer_instances` / 台账查询）与 depth 绑定族（`subagent` / `advisor` / …）——那些工具参与的选择面不在本面。
- ③ 单发单轮（`maxRounds = 1`）⇒ 无「读过工具结果后修正选择」面、无跨步序面。
- ④ 工具不真执行、题面中的路径为假想路径（无文件系统）——判定只看参数成形。
