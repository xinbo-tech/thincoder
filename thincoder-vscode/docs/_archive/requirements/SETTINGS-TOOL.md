# settings 工具（SETTINGS-TOOL）— 需求

> 板块：`settings` 工具（agent 可调的配置面）。需求层文档（`docs/requirements/`）。
> 定位：本仓机制实况登记——实现 `src/agent-tools/settings.mjs`（261 行）；注册面 `src/agent/setup.mjs`（主 agent 只读动作集）；
> 写盘面 = 共享 `~/.thincoder/config.json`（`src/config-io.mjs`（W16 已迁核收口——现体见批次档 §5））；部分承载 = `docs/design/TOOLS.md` §5。
> 跨端：与 CLI 仓同名需求档语义同源（同源形状表）；本端独立实现。

## 1. 总体目标

agent 需要在不打断会话的前提下查看 / 修改运行配置（模型、轮次、压缩阈值、advisor、traces 等）。
`settings` 工具把该面收成**受形状护栏的读写通道**：写盘 = 两端共享的 `config.json`，热应用 = 当前会话的 live 配置；
写入前做已知键校验与敏感键遮蔽，避免 agent 写出结构不符 / 泄漏凭据的内容。

## 2. 功能性需求

| # | 需求 | 验收语义 |
|---|---|---|
| F1 | 只读动作面 | list / get 类动作为只读——主 agent 面可调（与 memory 同分类），不需写权限 |
| F2 | 写动作 = 写共享配置 | `set` 类动作写 `~/.thincoder/config.json`（两端共享单文件）+ 热应用到 live 配置 |
| F3 | 已知键校验 | 非 null 叶子由默认值表（agent / traces 默认集）派生——按规范全路径寻址，不手写镜像表 |
| F4 | 形状护栏 | 不可消费形态明确拒绝（不落盘、不热应用）；null 叶子与跨端 / 同族键走显式形状表 |
| F5 | 敏感键遮蔽 | 键段判定命中（apiKey / key / token / secret / password）→ 值遮蔽展示（读面不泄漏凭据） |
| F6 | 并发写冲突可见 | 目标文件被并发改过 → 拒绝本次写并返回同型冲突提示（不静默覆盖） |

## 3. 非功能性需求

| # | 维度 | 标准 |
|---|---|---|
| N1 | 防漂移 | 形状表与默认值表同源；新增键 → 护栏同步（漂移由用例锁） |
| N2 | 成功即生效 | 写盘成功 = 该配置对当前会话后续运行立即生效（无重启要求） |
| N3 | 零凭据落输出 | 工具输出永不含明文凭据（敏感键一律遮蔽） |
| N4 | 可测试 | 工具形状、null 叶子、跨端键、描述句由用例逐条断言；登记入测试清单 |
