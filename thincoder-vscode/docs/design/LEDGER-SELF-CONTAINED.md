## 4. 架构 / 接口 / 数据流契约

### 4.1 自持边界契约（两条轴）

| 轴 | 管什么 | 判据 | 落点 |
|---|---|---|---|
| **轴一：条目 / 归属** | 台账条目、批次档范围、需求归属 | **本仓可解析**（路径形态必须以**本仓根**为基根可解析） | 本端检查器 L4 + 提示词自持节 |
| **轴二：正文引用形态** | 文档正文引用他仓文档 | 既有 V1 跨仓边界（`名称（仓别）§N` = 显式域外；带 `.md` 形态 ⇒ `unknown-doc`） | 本端 `docs/design/README.md` 规则 6 + `scripts/check-doc-width.mjs` `checkSectionRefs` |

**两轴并列、射程不重叠**：正文可以指他仓（规范形态），**条目与归属不行**。

### 4.2 本端台账条目契约（L4 输入面）

| 形态 | 判据 | L4 要求 |
|---|---|---|
| 指针 `X.md` / `X.md §N` | 既有 REF 形态 | 以**本仓根 + 台账目录**为基根可解析；否则 `[L4]` |
| 证据 `path.ext:line` | 既有 EVIDENCE 形态 | 路径段须在**本仓根**内为文件；否则 `[L4]` |

**不入判据（零假阳面）**：无路径散文（对位声明 / 镜像登记）· `名称（仓别）§N` 规范形态 · 组标题行。

> **收紧（B16）**：「散文不入 L4 判据」**不等于无约束**——允许形态为**封闭枚举 E1–E5**（§8.10.1）；枚举外形态（携 `.md` / 路径前缀 / 裸节号）由本端检查器 **V4** 判红。L4 管条目位（轴一），V4 管正文形态（轴二）。

### 4.3 跨端互引形态规范

两侧批档 / 台账互引按**轴二**规范形态：`名称（仓别）§N`（去 `.md` 后缀、去路径前缀）。

- 本档引用对端记录写 `LEDGER-SELF-CONTAINED（CLI 仓）§2`。
- 本档 `§1` 内的对端路径写法为**本批前形态**，随本批按规范形态收敛（本端由主 agent 落笔）。
- **范围（修正轮补充）**：本形态自本批新档起生效——两侧设计档 / 需求档自身的跨端引用同循（收敛面 = 本批新档 + 两侧批档 `§1`；存量档按 §8 处置）。

### 4.4 数据流

```
本端台账 docs/TODO.md
   └─ 路径形态 ─┬─ 指针 X.md §N → 基根=(本仓根, 台账目录) → 不可解析 ⇒ [L4]
                └─ 证据 p:f      → 基根=(本仓根)          → 不可解析 ⇒ [L4]
   └─ 基线分流 test/fixtures/ledger-baseline.json（本批新建 —— 实测不存在）
        ├─ 新增 ⇒ 阻断（退出码 1）
        └─ 存量 ⇒ **不得常驻**（「入基线」已废——阈值 = 0；现存键逐条修掉，§8.10.3）
```

### 8.10 例外判据（先例不构成例外依据——B16 / F14）

> **机制含义**（用户 2026-09-12 11:40 裁定）：「**你看，先例的作用大吧？用先例破规则是模型骨子里的训练。**」——**规则的有效性不能依赖模型的自觉**：凡「看得见的旧形态 / 登记在案的存量」都会被下一个 agent 当依据，**用先例免掉判断**。
> 故「先例 / 存量 / 已落形态」**不构成偏离规则的依据**；**例外的唯一依据是判据句（可机判）**。

#### 8.10.1 A 类（叙述性提及）→ 封闭形态枚举（判据面 = 本端检查器 V4）

**收紧判据**：A 类「叙述性提及零改」**不再是概括豁免**——允许形态**仅限 E1–E5**；**凡携 `.md` 后缀 / 路径前缀 / 裸节号（未附「名称（仓别）」的 `§N`）者一律改归 B 类**，逐条规范形态化。

| # | 允许形态 | 语义 | 机判表达式（逐行；枚举内 = 通过） |
|---|---|---|---|
| E1 | `名称（仓别）§N` | 引用他仓板块档 | `[A-Za-z0-9_\-]+（[^（）]{1,12}仓）\s*§\s*\d+(?:\.\d+)*` |
| E2 | `名称（仓别）` | 无节号（迁移档名 / 台账 / 目录 / 板块档泛指） | `[A-Za-z0-9_\-]+（[^（）]{1,12}仓）` 且**其后不接** `§` |
| E3 | `路径（仓别）` | 实施面文件坐标（保留相对路径与后缀） | `[A-Za-z0-9_\-]+(?:/[A-Za-z0-9_\-.]+)+（[^（）]{1,12}仓）` |
| E4 | 裸仓名（仅仓别词：`<名> 仓` / 仓目录名） | 不携档名 / 节号 / 路径 | 仓别词命中，且同一 token 不携 `.md` / `/` / `§` |
| E5 | 纯语义提及（对端 / 另一端 / 多端镜像 等） | 不携任何坐标 | 该行**零** `.md` 后缀、**零** `/` 路径段、**零** `§` 节号 |

**判红规则（枚举外即红——本端检查器 V4「跨仓形态合规」，fail-closed；逐项以实装为限）**：同一行内「**对端仓指标**」与下列任一**枚举外坐标**共现 ⇒ 违规（退出码 1）：

- ① 档名 + 文档后缀（`.md`）——**带对端坐标 / 仓标触发者判**（路径形 + 仓标形）；**无对端坐标的裸档名（`X.md §N`）不入 V4**（归 V1 面——两判据不重复报同一行）；
- ② 跨仓路径前缀（兄弟仓目录名 + `/`）——**以 `.md` 副本为限**（非 `.md` 路径不入——与 D19 二分判据自洽）；
- ③ **裸节号**——`§N` 未紧附于「名称（仓别）」；**实装 = 紧邻形态**（仓标 + `§N`）；孤立 `§N` 无对端指标（触发条件不可判）不入；
- ④ 仓目录名直引——由 ① 前段承载（仓目录名 + `/` + `.md`），同属 ② 的 `.md` 射程界。

**射程豁免（硬——父侧裁定）**：**fenced 代码块整块跳过**；**行内命令**（码段含 `cd … && …` / 命令词）· **搜索模式串**（码段含 `[^` / `\.` / `(?<` 等片段）⇒ **整行不判**（可执行坐标——证据与命令保字面，与 D19 同类）。

**引述（旧形态对照）不是允许形态**：审计对照所需的旧形态以**断开书写**呈现（形如本行前段——反引号切断档名后缀与节号的连续形态），令判据不命中；**连续书写即命中**。这是**表现协议**、不是豁免：可见文本里仍不得存在连续的枚举外形态（**豁免面内除外**）。

#### 8.10.2 D19「实施面文件坐标」→ 机判式（并说明为何不是「跨仓登记」）
