## 1. 总体定位

工具系统 = 工具实现面（`src/tools/*.mjs` + `src/agent-tools/*.mjs`）**+** 工具描述面（`src/tools/*.md`，文本行本体归提示词面）**+** 注册表（`agent-tools.mjs` / `cli/make-agent.mjs` ↔ VSC `agent-tools/index.mjs`）**+** 单端独有实现。
本档只收**实现面与工具行为契约**（工具描述文本与槽位提示词的行本体住提示词面子系统档）。
本板块对本子系统的要求 = 对称面归一为**核内单一实现**；工具可见输出 / 回话面的归一变更**保留兼容并逐条登记**。

> 面清单与逐面裁决（分类 / 端差处置 / 前提校验 / 归属段）→ `docs/design/TOOLS.md` §1–§2（不复制）。

### 4.1 总体需求

工具是模型作用于外部世界的**唯一入口**。工具系统必须做到：注册面单一可枚举、调度确定、安全边界可解释、
描述文本足以让模型正确路由、**配置申报与消费一一对应（无死键）**。

### 4.2 功能性需求（F1–F7）

| # | 需求 | 说明 |
|---|---|---|
| F1 | 注册面单一 | 工具注册表是权威列举面——新增 / 删除工具须改一处且可被探针枚举 |
| F2 | 描述六要素 | 工具描述（md / 内嵌）必含六要素（见设计档 §6.9） |
| F3 | 描述多端一致 | CLI / VS Code 同语义（逐字锚走评审流程） |
| F4 | 触发即证据 | 工具执行期间的 console 输出回显到结果 |
| F5 | 交互轻量 | 工具不该与用户对话；需用户输入的场合由专门机制承担 |
| F6 | `websearch` 后端选择面单一 | 后端由 `websearch.apiKey` 触发（有 key → Tavily；无 key → Bing 兜底）；不设独立后端选择键——`provider` 死键已移除 |
| F7 | 描述装载面双端同构（VSC） | VSC 端工具描述 = 外部 `.md`（`DESC()` 同语义装载）+ Routing / Notes 段在位 |

### 4.3 非功能性需求（N1–N9）

| # | 维度 | 标准 |
|---|---|---|
| N1 | 安全模型 | 信任模型 + 审批门控 + 快照为真实防线——不以文本匹配拦截破坏性操作 |
| N2 | 路径边界 | 无边界解析：相对路径相对 cwd、绝对路径原样、符号链接正常跟随；无目录限制 |
| N3 | 命令 | 零文本拦截：破坏性命令一律放行，走审批 + 快照；仅保留危险标注；bash 超时 120s |
| N4 | 网络 | SSRF 防护；响应体 ≤ 5MB；HTML 转文本 |
| N5 | 资源上限 | read ≤ 2000 行 / 输出 ≤ 200,000 字符（超限落盘 + 预览）；write 前自动语法检查（JS） |
| N6 | 执行边界 | `execute` = 纯净 node ESM 子进程，与 bash 同边界；文件能力唯一入口 = 专用工具；超时 SIGKILL（默认 30s / 上限 600s） |
| N7 | lint 零依赖 | `node --check` 快路径 + 语言级联；eslint 级联已删 |
| N8 | 配置面诚实 | 工具配置的申报面（DEFAULTS / 配置文档模板 / 两端写入面）与消费面一一对应：申报键必有读取点；无读取点的键不申报（发现即删） |
| N9 | 描述打包面（VSC） | 外部 `.md` 描述随扩展打包（`.vscodeignore` 不排除） |

### 4.4 范围边界（不做）

- 不做文件系统沙箱 / 目录白名单（N2：信任模型取代）。
- 不做命令文本黑名单拦截（N3：安全剧场）。
- 不做 `execute` 的 import 阻断或伪沙箱（历史 `exec-prelude` 已退役）。
- 不设 websearch 显式后端选择键（后端选择由 `apiKey` 触发承担；多后端并存到来时另批设计选择面）。
