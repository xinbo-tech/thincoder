## 1. 总体需求

TUI 是 CLI 的主界面：流式输出必须**看着像活的**（新内容自动进视野、用户看的地方不跳），
历史会话必须**能翻到底**且不因体量变大而卡。

子代理活动区块（运行面板 / 冻结块）与工具块同款：最新活动在折叠态直接可见（tail），全量内容
随展开可达，同一活动不重复承载。

## 2. 功能性需求

| # | 需求 | 说明 |
|---|---|---|
| F1 | 流式跟随尾部（2026-08-31 用户需求） | 默认跟随——最新内容钉在视口底；tool 行 / pushLine 同样生效，无"跟随空洞" |
| F2 | 上滚暂停跟随 | 用户上滚（PgUp / 滚轮上）→ 暂停跟随 |
| F3 | 锚定补偿 | 暂停期间内容增长不得把用户正在读的行顶走——渲染帧按增量补偿 scroll（视口顶保持绝对行）；loadOlder 加载后同样补偿 |
| F4 | 恢复跟随 | PgDn / 滚轮滚回底部 / 新提交消息 → 恢复跟随 |
| F5 | 滚动入口明确 | 滚动入口 = PgUp/PgDn + 滚轮（↑/↓ 归输入框内语义——历史导航 / 多行竖移，见 F11；**不执行会话滚动**） |
| F6 | 懒加载（2026-08-31 用户需求） | 恢复只加载最近 200 条；向上滚到顶 → 自动加载更早一页（20 条）；滚轮/PgUp 双入口同一判别式。**2026-09-11 修订（TUI-OOM-ROOTCAUSE 批）**：数据源 = 会话记录存储（磁盘为准——`SESSION.md` §14.1）；内存层不再驻留全量、翻页不往内存累积；翻页锚定恢复时点绝对序号；交互/页大小/缓存层不变 |
| F7 | 头部分页标记 | 会话顶部显示 `… N more earlier messages …` 维护 |
| F8 | 子代理内嵌套活动的显示同款（2026-09-11 用户报告——口径 C） | 子代理块内嵌套 spawn（eng-coder 内 explore 等）的活动行**直接进入该块 tail**——与其他工具调用同款；任意嵌套深度的全量内容随该块展开可达。范围边界：仅 CLI TUI 子代理活动区块（运行面板 + 冻结块）；主 agent 自身 spawn 的显示面不在本项内；嵌套层独立小节/折叠入口的存废为设计裁定项（本批裁定 = 取代——全量随外层展开可达） |
| F9 | picker 附注渲染（2026-09-11 第 20 批） | picker 条目附注（`item.note`）在条目行渲染可见；渠道警示（`(no key)` / `(不可用)`）在条目行**恒可见**（不因窄终端截断丢失）。判定句：给定 provider 条目 + 80 列渲染 → 行文本含警示串；含 note 条目行尾部渲染 note（`  ` 分隔）；无 note 条目行形态零回归。范围边界：仅 CLI TUI 选择面（条目行渲染 + 渠道条目产出）；不改 picker 过滤/鼠标/栈/键盘语义 |
| F10 | 选择面分工与交互契约（2026-09-11 第 20 批） | question / wizard / picker 三面**保留各自职责**（提问工具面 / 首启向导面 / 全功能菜单面），交互按同一契约对齐：① 同义键同形（↑↓ 环绕）② 选中项恒在可视窗内 ③ 面特有键（过滤/鼠标/层级栈/独立位置指示）明示豁免。判定句：契约表在设计档 §12 落档；question 选项 ↑↓ 环绕（末项 down → 第 0 项；首项 up → 末项）；wizard provider 步选中项越窗后自动滚入可视窗。范围边界：不合并三面实现；各面 Esc / Enter 流程语义不变 |
| F11 | **输入框方向键编辑：↑↓ 竖移 + Inject 框四方向键**（2026-09-11 第 31 批） | 主输入框 ↑↓：**多行**（可视行口径——折行与 `\n` 同权，与 zsh/readline 惯例 + VSC webview 先例（`webview/input.js:76-84`，VSC 仓）一致）时框内竖直移动（按**显示列**保持 + 目标行短则钳制行尾）；不可竖移时 ↑ 回落输入历史、↓ 无动作；**正在翻历史（`historyIndex ≠ -1`）时恒为历史导航**（不竖移）。Inject 框（Ctrl+I）：`{ chars, cursor }` 模型 + 四方向键可编辑（←→ 逐字符、↑↓ 折行竖移、边界吞——无历史回落）；其余编辑键 = 自由文本最小集（Home/End/Ctrl+U/Backspace/可打印/Ctrl+V 落光标）。processing 期：竖移放行（纯编辑）、历史导航禁（回落分支吞）。判定句：给定多行输入且光标非首行 → 按 ↑ → 光标至上行同显示列（短行钳制行尾）；给定单行输入 → 按 ↑ → 进入历史（`historyIndex` 变、草稿入 `_draft`）；给定 `historyIndex ≠ -1` 且当前为多行历史条目 → 按 ↑ → `historyIndex` 递减、input 换为前一条（光标随条目末重置——不竖移）；给定 `processing` + 多行（光标非首行）→ 按 ↑ → 光标上移且 `historyIndex` 不变；给定 Inject 框折行文本 → 按 ↑/↓ → 光标行变化且列保持、边界无副作用。范围边界：不改 question 自由文本态 / search / picker / wizard / permission 键语义；Inject 框保持单行不变式（不插换行）；不引入列记忆状态；不做 VSC 端改动（其 webview 已有同款规则，差异仅报告）；竖移不跨出输入框（不滚动会话——F5 保持） |
| F12 | /advisor 子菜单可开 + picker entries 契约（2026-09-11 第 28 批） | `/advisor` 交互菜单子面（Thinking 等）打开不抛错——子菜单以真实条目列表打开（Thinking 子面含 `Use main model settings` 与 effort 条目）。picker 调用契约：`showPicker(title, entries)` 的 `entries` 必须是数组——非数组（含漏 `await` 的 Promise）→ **显式 TypeError**（Promise 输入附 `await` 提示），不得静默、不得裸抛 `entries.filter is not a function`。判定句：脚本化 picker 驱真 `handleAdvisorCommand`——主菜单选 Thinking → 第二次 showPicker 调用的 entries 为真数组（含 `action:"inherit"` 条目）且全程无 `[error]`；真 `createPickers` + Promise 输入 → 同步抛 TypeError（子串 `entries must be an array`）。范围边界：不改 picker 渲染/过滤/导航/栈语义；不改其它命令菜单；不引入异步 entries 支持（契约 = 调用方 await） |

| F13 | **用户介入提醒（attention 态）**（2026-09-11 第 33 批） | 出现「需要用户介入」的情况时，界面出现可见的 attention 态提醒（用户原话（#IKDCVV）：「底部任务栏的变色提醒——不用反复切回来」）。**触发集合 = 审批卡挂起（权限确认）/ 提问卡挂起（question）/ 回合结束等待输入（顶层回合链彻底结束、无自动续跑）**。CLI 形态 = 状态栏整行变色（注意力底色 + 提示语前缀——色/文案在设计档逐字）；VSC 形态 = 面板/状态栏 attention 态（语义同源、各端独立实现——VSC 实现与文档为另链）。消除 = 用户任意输入（键盘/鼠标）或提示消解后复位。判定句：① 三触发态任一存在 → 状态栏渲染含注意力色序列与对应提示语（逐字——设计档 §14.3）；② 用户输入（任意键/鼠标）后「回合结束」态复位（再渲染为常态）；③ 审批/提问两态随提示消解实时消失（派生——零残留）；④ 非触发态（用户自发的 picker/wizard/search、无审批/提问卡挂起的 processing、挂起会话、pendingInput）不出现 attention 态——processing 的豁免仅及 awaiting 派生；审批/提问卡挂起在回合中同样为 blocked（正确提醒——设计档 §14.3）。范围边界：仅应用内可见态（不做系统级通知/终端标题/响铃）；不改状态栏既有信息面（增量）；不闪烁；不做 VSC 端实现（另链） |

## 3. 非功能性需求

| # | 维度 | 标准 |
|---|---|---|
| N1 | 滚动/加载不卡 | 三层缓存（全量 convCacheKey / 行级 wrapRowsCached / 段级 `_lineSegCache`）——loadOlder 只算新增行，rebuild 111ms → 5-8ms 平坦 |
| N2 | 不随历史增长劣化 | 段缓存后 rebuild 耗时与已加载历史无关 |
| N3 | 跨端对齐 | 分页大小与 VS Code 端 parity（`HISTORY_PAGE_MESSAGES` ↔ `HISTORY_PAGE_SIZE`） |
| N4 | 零依赖 | 裸 ANSI 转义自研渲染（零 npm 依赖政策） |
| N5 | 防刷屏与行额度 | 折叠态子代理块不因嵌套活动增加常驻行（头 1 行 + tail ≤3 行；嵌套活动不另起小节）；展开态 ≤60% 屏高（既有）；内层内容计入外层块 500 行环（单环——总预算不变） |
| N6 | 省略计数真值 | 块内「已省略 N 行」的 N = 该块实际被隐藏的内容行数——省略标记自身不占额度、不计入 N；无幽灵增量 |
| N7 | 选择面行宽预算（2026-09-11 第 20 批） | picker 条目行渲染宽 ≤ `cols − 8 − 指示位宽`（8 格余量 + 首/末行 `↑ more`/`↓ more` 指示——既有口径；**判定以判定式为准（修正轮 #6）**——指示位宽在 8 格外另扣，含指示行在内整行仍 ≤ `cols − 8`）；超宽右截断 + `…`；行尾附注段（note）为最先牺牲段。判定句：任意渲染行 `stringWidth ≤ cols − 8`（含指示行）；超长 note → 截断带 `…` 且行宽不超预算 |
| N8 | 方向键编辑约束（2026-09-11 第 31 批） | ① 竖移按**显示列**（CJK/emoji 不劈半——非 UTF-16/codepoint 计数）② 单行/空输入 ↑↓ 语义与改动前逐字一致 ③ 状态对象零增（列保持逐键现算，不引入列记忆等新字段）④ 零新依赖。判定句：CJK 用例（`["中","文","\n","a","b"]` 自第 2 行尾按 ↑ → 光标落 `中` 之后 = 显示列 2，非第 2 个 codepoint）；空输入 + 空历史按 ↑ → 无副作用；既有锁档（`test/input-lock.test.mjs` 等）全绿 |
| N9 | attention 零侵入 + 可机判（2026-09-11 第 33 批） | ① 既有状态栏信息面零改（模式/耗时/token/上下文/busy/快捷键照常——attention 为增量包裹）；② **零新定时器**（稳态色——不引入空闲重绘）；③ 派生为**纯函数**（state 事实 → attention 种类；可直测）；④ 宽度预算保持（整行 ≤ `cols − 1`——既有口径）；⑤ 新档测试 glob 自动发现、零长等待；⑥ 触发/消除为状态位驱动——不解析模型输出。判定句：attention 为 null 时状态帧与改动前逐字节等价（机判口径 = 零 `\x1b[43m` 序列 + strip-ANSI 文本无 chip——与设计档 §14.3 / T-AT2 同口径）；非 null 时含注意力色序列 + 提示语（逐字）且 strip-ANSI 后文本以提示语开头；派生纯函数矩阵直测；`node test/run-fast.mjs` 全绿 |
| N10 | 会话显示层内存有界（字节维度——2026-09-11 TUI-OOM-ROOTCAUSE 批） | 显示层全部文本载体有界：① 逐行字符上限（pushLine/pushLabel/恢复行——超限截断加标记，全文在会话记录）；② 各载体字符额度（工具参数 JSON / 工具结果 / 输出环条目 / 子代理块 / 评审块与流式缓冲）——超限裁最旧（与既有行数环同族，省略标记语义 N6 不变）；③ `state.lines` 总量字符额度（任一路径超限 → 与既有 5000 行环同款裁头）；④ 懒加载翻页不无界累积（额度内）。判定句：模拟超长输入（单行 10MB / 无换行巨 chunk 子块 / 满会话翻页到底）→ 各载体与 `state.lines` 字符总量 ≤ 设计档常量且标记行可见；既有行数口径（5000 行环 / 500 行块环 / 200 行输出环）与折叠语义零改；`node test/run-fast.mjs` 全绿 |

## 4. 范围边界（不做）

- 不做鼠标全交互（仅滚轮滚动有支持；其余键盘驱动）
- 不做悬停提示（工具参数全量落 dim 行——TUI 无悬停面）
- 嵌套层独立折叠入口（每层独立折叠键）不做——本批设计裁定为**取代小节**形态（全量内容随外层块展开可达；理由与影响见设计档）
- 主 agent spawn 的显示面不动（运行底部面板 / 冻结块 / ⏹——用户限定「不是主 agent 调用的时候」）
- 嵌套头行补任务摘要（候选 A）与「仅去掉小节结构」（候选 B）不在本批范围（用户口径 C 选定）
- 不合并 question / wizard / picker 三面实现（第 20 批 F10 裁定 = 分工保留 + 契约对齐；合并属架构级重做——另案）
- 不给 wizard provider 步 / question options 增加过滤、鼠标、层级栈（面特有键豁免——设计档 §12 契约表）
- 不做 VSC 端方向键编辑改动（其 webview 已有同款先例，差异仅报告）；不改 question 自由文本态键集；不引入列记忆状态（第 31 批 F11 边界——输入框竖移 / 注入框光标面）
- attention 态不做闪烁 / 系统级通知 / 终端标题改写；不改状态栏既有信息面与既有按键语义（第 33 批 F13 边界；VSC 端实现+文档为另链——语义同源、各端独立实现）
- 显示层字节额度不做内容语义压缩（只截断加标记——全文在会话记录）；不改行数口径与折叠/展开既有语义；不影响恢复保真（恢复内容仍为 slim 后记录——与既有口径一致）（TUI-OOM-ROOTCAUSE 批 N10 边界）
