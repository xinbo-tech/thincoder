### 4.3 A1 用例号锚

- **抽取式**：`(?<![A-Za-z0-9_-])T(?:-[A-Za-z]{1,4})?-?\d+(?:[.-]\d+)*[a-z]?(?![A-Za-z0-9_-])`，且 token ∈ {`T-…` 前缀形, `T<数字>` 裸形}。
- **形态拆解**：范围 / 并列书写（`T-VS1–T-VS6` · `T-CP1..T-CP19` · `T-VS32/T-VS35`）**逐 token 独立抽**——端点各自判，不作整体。
- **排除式**：① 前缀非 `T` 的内部编号（`AC-…` / `F…` / `N…` / `D…`）**不入**（设计档内部编号 ≠ 用例号——假阳类①）；② token 附在码段内且行属 P2 面 → 整行跳过。
- **存在性判据（口径写死——评审轮次 1 #4）**：**认用例标题**——目标域内的**用例注册调用**（本仓库存形态 = 顶层 `test(` / `slow(`——首参字符串字面量；库存口径句见 `test/slow-gate.mjs`）标题含 token（右界判）⇒ 在册；**「任一档含」不计**——注释 / 清单 / 变量数组内的提及不构成在册（**右界为判据的一部分**——`T-VS3` 不得由 `T-VS32` 满足）。
  **假阴面（如实登记）**：标题判定 = 调用形态文本匹配——**被注释掉的注册行 / 注释内模拟标题**仍满足「在册」⇒ 该形态漏报（注释语义机器判不了）；**覆盖边界**：本仓用例注册形态 = 顶层 `test(` / `slow(`（库存口径句）；形态外新写法（如动态标题）出现时按判红处置（消解 = 把用例号写回标题）。
- **症状串**：`用例号锚不在册（test/ 树无此用例号）`。

### 4.4 A2 符号锚

- **抽取域**：行内反引号码段内的**单 token**（不含空白）。
- **强形态判据**（须命中其一）：camelCase（含 ≥1 处小写→大写跃迁）· snake_case / 下划线前缀（`_x`）· 全大写常量（`[A-Z][A-Z0-9_]{3,}`）· 点径（`a.b`——判首段）。
- **排除式（逐条）**：① 含 `/` 或带代码 / 文档后缀 → 归 A3；② token == 源域或本仓 `docs/` 树任一 `.md` 档名去后缀（**档名主干——派生排除，非词表**）；
  ③ **平台 / 库 API 词表**（判据句：**不是本仓命名空间的名字，不属「本仓自建符号」的定义域**——**非豁免通道**）：派生判据（词条来源面三类）= ① Node 内置模块面（`node:` 模块导出族）② DOM 接口面（浏览器平台接口）③ `vscode.*` 命名空间（扩展宿主 API）；
  **载体** = `scripts/check-doc-anchors.mjs` **导出常量**（词表单源——测试可导入核断言；不散落多档）；**扩充规则** = 新增词条须引上列判据句之一（一条词条 ↔ 一条派生命名面），**不得逐项豁免**（F14——无「单词条特批」通道）；
  ④ 平台码形态 `^[A-Z]{2,5}\d{3,}$`（如 `TF400813`）；⑤ 通用词 / 字面量（长度 < 3 · 纯小写单词 · `true|false|null` 等）。
- **存在性判据**：token（或点径首段）在本仓代码面以**词界**命中 ⇒ 通过；否则在**对端仓代码面**命中 ⇒ 通过（跨仓参照面）；两处皆无 ⇒ 判。

### 4.5 A3 路径锚

- **抽取式**：行内反引号码段内 —— ① `(?:段/)+名.(mjs|js|json|md|css|html)` ② 裸 `.md` 档名；可带 `:行号` / `:行号-行号` 尾（行号 / 区间均**不参与**存在性判——剥除后按裸路径判）。
- **排除式（逐条）**：
  1. 首段 ∈ {`..`, `~`, `.thincoder`, `node_modules`, `.git`} ⇒ 非仓档坐标（运行时 / 用户态 / 依赖面）；
  2. 首段 = 任一仓目录名（本仓名 / 对端仓名）⇒ 带仓前缀（规范形态 = **去仓前缀**——F13 / E3）；
  3. 同行带 `§N` 且 token 为 `.md` ⇒ **归 V1**（不重复报行）——**仅 `.md` token 免判；非 `.md` 路径 token 照判**（§ 不构成其豁免）；
  4. token 后紧跟 `（…仓）` 注记 ⇒ **E3 允许形态**（域外坐标——归 V4 面）；
  5. **示例占位与通配形态**（判据句：命名约定与模板引例——**不指向具体现态档件、存在性无可判面** ⇒ 一律不入判；**射程** = 仅及 token 自身形态——出现即排除、无名单、非逐项豁免）：
     ① 段名 / 档名主干 ∈ {`x`, `foo`, `bar`, `path`, `to`, `name`, `notes`, `demo`, `example`, 单字符}；
     ② 段名 / 档名含通配符 `*` 或角括号占位 `<…>`（约定引例——零报样例：`docs/TODO*.md` · `docs/batches/<批>-<主题>.md` · `src/prompts/advisor-*.md`）。
  6. 首段以 `-` 开头（并列斜杠书写伪影）。
- **存在性判序（与台账机检 L4② 同一函数——判据单源：`scripts/check-ledger.mjs` 导出 `evidenceState`、V5 导入复用，不复制实现；不发明第二套定位语义）**：

  | 序 | 判 | 结果 |
  |---|---|---|
  | ① | 仓根直接解析（`existsSync(仓根/token)`） | 通过 |
  | ② | 陈旧 / 省略前缀：首段须为**仓根现存条目**，且 basename 仓内唯一 | 通过 |
  | ③ | `.md` 裸档名：仓内同名 `.md` ≥1（**现态面**） | 通过 |
  | ④ | basename 仓内多义（≥2） | **判**（不可定位——须带目录前缀） |
  | ⑤ | 0 命中 | **判**（不存在） |

- **症状串**：`路径锚不可定位（本仓现态面不可解析）`。
