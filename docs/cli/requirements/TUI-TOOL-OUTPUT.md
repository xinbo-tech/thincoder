# TUI 工具输出（行间区块）· CLI 面 · 需求

> 板块 = **TUI 工具输出**——CLI 终端界面里普通工具调用的显示形态。
> 配对设计档 = `docs/cli/design/TUI-TOOL-OUTPUT.md`。
> 建档：2026-09-15（**B 式迁移轮 · 第 6 批**——`thincoder-cli/docs/requirements/TUI-TOOL-OUTPUT.md` 内容重建入基准层；
> 旧档原地一字不改、留作参照历史）。层归属 = **CLI 面**（P2——终端界面结构性只属 CLI；VSC 无行间区块面）。

## 1. 总体需求

TUI 的工具输出统一为**行间区块**：每次工具执行在对话区产出「标题行 + 执行中滚动内容 + 完成行」，
随会话流自然滚动——用户不必去别处找工具在干什么。

**范围边界（明确不做）**：本档只述需求；区块的渲染契约、生命周期与共享守卫 = 设计档。

## 2. 功能性需求

| # | 需求 | 说明 |
|---|---|---|
| **FR1** | **每次调用一个区块** | 每个工具调用产生一个行间区块，含工具名 + 参数摘要作为 title（如 `❯ write src/x.mjs` / `❯ bash npm test`） |
| **FR2** | **执行中滚动显示** | 内容以 `│ ` 前缀滚动显示，默认保留最近 N 行（N = `agent.streamPreviewLines` ?? 工具限定值 ?? 5）；溢出折叠为 `│ …` |
| **FR3** | **完成行** | 工具完成时清掉滚动块，追加完成行 `❯ name — done (耗时) → 摘要`（含 OK / FAILED 语义） |
| **FR4** | **完整输出不受区块限制** | 超长结果按落盘机制保留（阈值权威 = `docs/core/design/TOOL-OUTPUT-LIMITS.md`）；行间区块只做预览，模型从 history 读取完整结果 |

## 3. 非功能性需求

| # | 维度 | 标准 |
|---|---|---|
| **NFR1** | 性能 | 区块渲染与行间消息同开销；流式追加走增量渲染路径（`scheduleRender`），不触发全量重绘 |
| **NFR2** | 可维护 | 输出经 `onToolOutput(name, chunk)` **单一入口**；chunk 契约见设计档 §3 |

## 4. 范围边界（不做）

- 不做工具**面板区**（面板 / 行间双轨已废除——行间区块是唯一形态）。
- 不承载子 agent / advisor 活动（专用分支——见 `docs/cli/design/TUI.md` §6）。
- 不做悬停提示（TUI 无悬停面——参数全量落 dim 行）。
