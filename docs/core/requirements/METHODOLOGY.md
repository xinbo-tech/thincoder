## 1. 总体定位

方法论需求 = 给「怎么做才正确」画**执行判据**的一层需求：三观定「你是谁 / 为什么」，方法论定「怎么做」。
**两模式遵循同一套规则**——同一个判据集（三观 + 本档 + 公共层 + 工具面）；**差别只在流程强度**：工程模式 = 强流程（约束靠**结构**实现），普通模式 = 纪律驱动（无结构约束）——**不是两套标准，也不是「严 / 松」两档**（2026-09-18 用户裁定）。
各模式需求档（`docs/core/requirements/ENGINEERING-MODE-V2.md` / `NORMAL-MODE.md`）是这些判据的**实例化执行面**。本档只登记需求的「什么」与**可机器验证的判定句**——机制正文一律指针、不重述（D2）。
