## 1. 总体定位

模型需要**操作真实浏览器**（访问 JS 渲染页面、多步点击填表、抓取交互后数据、走查/回归页面）——而不是只读静态 HTML。
`browser` 工具把该面收成一个**有状态的受控通道**：工具自启一份系统浏览器（Edge/Chrome——**独立 profile**，不碰用户日常实例），经 CDP 驱动；每次动作回执「可交互元素紧凑清单 + 元素引用」，模型按引用步进。

## 2. 功能性需求

| # | 需求 | 判定句（可机器验证） |
|---|---|---|
| **F-BT1** | 自启浏览器（无接管 · 无扩展） | 给定装有 Edge 或 Chrome 的机器，工具首用即自启一份浏览器 + 独立 profile（`user-data-dir` 非默认）+ CDP 端点；**零依赖**于任何在跑的用户浏览器实例、浏览器扩展、或预置调试口 |
| **F-BT2** | 无头 ∥ 有头双模式 | 动作/会话参数可切 headless=true ∥ false；两模式同一动作面可用；有头实例可见（用户可旁观；工具不设接管机制） |
| **F-BT3** | 动作面（多轮有状态） | 动作集含 navigate / snapshot / click / type / evaluate / wait / screenshot / close（名面由设计定）；每次调用作用于同一会话（页面/登录态/Cookie 跨调用保持）；navigate 后 snapshot 描述新页 |
| **F-BT4** | 元素引用步进 | snapshot 回执 = 可交互元素（链接/按钮/输入/可点项）紧凑清单，每项携**稳定引用**；click/type 以引用寻址（不要求模型猜选择器）；页面微变不使引用全失效（失效项在回执中显式标注） |
| **F-BT5** | 等待与稳定判定 | wait 动作（选择器/文本/网络静默/超时——形由设计定）；动作失败回执带**现场快照**（模型可据以纠正）；超时不无限悬挂 |
| **F-BT6** | 登录态持久 | 独立 profile 使登录态跨会话留存：用户在**有头**实例完成一次登录后，后续（含无头）调用即以该登录态运行（同 profile 内） |
| **F-BT7** | 写操作闸（安全） | 不可逆类动作（提交/删除/发送——判据面由设计定）受**审批门**控制（逐次确认 / 配置化允许清单——形沿既有审批/权限机制）；拒绝 ⇒ 不执行且回执明示 |
| **F-BT8** | 四端注册面 | 工具注册表（核注册面）含本工具，CLI / VSC / 桌面可用；无浏览器环境 ⇒ 显式不可用报错（不静默） |

## 3. 非功能性需求

| # | 维度 | 标准 |
|---|---|---|
| **N-BT1** | 零第三方依赖 | 实现只 import `node:*` 与仓内模块（CDP 走 Node 原生 WebSocket；浏览器 = 系统已装 Edge/Chrome） |
| **N-BT2** | 内容按不可信数据 | 页面内容（snapshot/evaluate 回执）按**不可信外部数据**处理——注入指令不构成工具指令（沿 MCP 面纪律）；回执标注来源 URL |
| **N-BT3** | 输出规模可控 | snapshot/回执有默认规模上限 + 截断标记（防长页面淹上下文——上限值设计定）；evaluate 回执同受上限 |
| **N-BT4** | 隔离与凭据 | profile 与用户日常浏览器隔离；工具不读写用户浏览器数据；工具输出不泄漏 profile 内凭据（未见性面由设计定） |
| **N-BT5** | 平台面 | Win/mac/Linux 浏览器发现（Edge/Chrome 候选表 + env 覆盖——沿 `scripts/console-walkthrough.mjs` 实证表）；启动失败 ⇒ 可读的错误提示 |
| **N-BT6** | 可测试 | CDP 客户端与快照逻辑可对假传输单测；真浏览器冒烟（本机 Edge/Chrome 无头）纳入批内件 / 走查 |

## 4. 范围边界（不做）

- **不做接管**（不连用户正在用的浏览器实例、不开发浏览器扩展、不做 WebView2/内嵌实例池）——用户 2026-10-07 13:10 明裁。
- 不做录制回放 / 工作流编排层（后议——真需求再立）。
- 不做全自动爬虫面（反爬规避 / 大规模并发抓取 / 自动凭据填充）。
- 不改 `web` / `websearch` 工具语义（静态抓取面照旧；本工具 = 其互补面，D2 各持权威）。
- 不引第三方浏览器自动化库（Playwright/Puppeteer 类——零依赖纪律）。
- 不建模型侧新机制（审批/权限沿既有机制消费，不新增门类）。

## 5. 依赖与关联

- **上游依赖**：系统装有 Edge 或 Chrome（无 ⇒ 显式不可用）；Node ≥ 24（核宿主底线）。
- **下游关联**：工具注册面（四端——F-BT8）· 审批/权限机制（F-BT7 消费）· 走查/测试实践（本工具的副产品用途——非需求）。
- **先例参考**（不复制，D2）：`scripts/console-walkthrough.mjs`（CDP 直控 + 浏览器发现 + profile 隔离的**已实证**先例，2026-10-07）· thinworker 邻仓「浏览器控制」设计档（工作区只读参考——双通道全方案；其扩展直连面 = 本工具明确不做面）· openclaw browser 工具档（选择序 / 权限模型）。
