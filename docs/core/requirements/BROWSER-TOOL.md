## 1. 总体定位

模型需要**操作真实浏览器**（访问 JS 渲染页面、多步点击填表、抓取交互后数据、走查/回归页面）——而不是只读静态 HTML。
`browser` 工具把该面收成一个**有状态的受控通道**：工具自启一份系统浏览器（Edge/Chrome——**独立 profile**，不碰用户日常实例），经 CDP 驱动；每次动作回执「可交互元素紧凑清单 + 元素引用」，模型按引用步进。

## 2. 功能性需求

| # | 需求 | 判定句（可机器验证） |
|---|---|---|
| **F-BT1** | 自启浏览器（无接管 · 无扩展） | 给定装有 Edge 或 Chrome 的机器，工具首用即自启一份浏览器 + 独立 profile（`user-data-dir` 非默认）+ CDP 端点；**零依赖**于任何在跑的用户浏览器实例、浏览器扩展、或预置调试口 |
| **F-BT2** | 无头 ∥ 有头双模式 | 动作/会话参数可切 headless=true ∥ false；两模式同一动作面可用；有头实例可见（用户可旁观；工具不设接管机制） |
| **F-BT3** | 动作面（多轮有状态） | 动作集含 navigate / snapshot / click / type / evaluate / wait / screenshot / close（名面由设计定）；每次调用作用于同一会话（页面/登录态/Cookie 跨调用保持）；navigate 后 snapshot 描述新页 |
| **F-BT4** | 元素引用步进 | snapshot 回执 = 可交互元素（链接/按钮/输入/可点项）紧凑清单，每项携**稳定引用**；click/type 以引用寻址（不要求模型猜选择器）；页面微变不使引用全失效（失效项在回执中显式标注） |
| **F-BT5** | 等待与稳定判定 | wait 动作（选择器/文本/网络静默/超时——形由设计定）；动作失败回执带**现场快照**（模型可据以纠正）；超时不无限悬挂 |
| **F-BT6** | 登录态持久 | 独立 profile 使登录态跨会话留存：用户在**有头**实例完成一次登录后，后续（含无头）调用即以该登录态运行（同 profile 内） |
| **F-BT7** | 写操作闸（安全） | 不可逆类动作（提交/删除/发送——判据面由设计定）受**审批门**控制（逐次确认 / 配置化允许清单——形沿既有审批/权限机制）；拒绝 ⇒ 不执行且回执明示 |
| **F-BT8** | 四端注册面 | 工具注册表（核注册面）含本工具，CLI / VSC / 桌面可用；无浏览器环境 ⇒ 显式不可用报错（不静默） |

**扩展轮：输入域最大化（CDP `Input` 域——2026-10-07 14:48 令）**

| # | 需求 | 判定句（可机器验证） |
|---|---|---|
| **F-BT9** | 键盘真输入（受信事件级） | `press` 动作：键位（Enter ∥ Esc ∥ Tab ∥ 方向键 ∥ 可打印键——键面由设计列全）∥ 修饰组合（Ctrl ∥ Alt ∥ Shift ∥ Meta）∥ 按下/抬起分离 ∥ 长按重复；发键前对引用目标**聚焦**；事件走浏览器输入管线（页面侧 `isTrusted === true` ∥ 真按键处理链可驱——参照 `Input.dispatchKeyEvent`） |
| **F-BT10** | 指针真输入（悬停/滚轮/坐标点击） | `hover`（悬停——hover 型菜单可驱出）∥ `wheel`（滚轮/指定滚动量）∥ `mouse`（坐标级：左/中/右键 ∥ 单击/双击 ∥ 按下/抬起分离）——坐标 = 视口 CSS 像素（元素引用可解析为坐标）；受信事件同上（参照 `Input.dispatchMouseEvent`） |
| **F-BT11** | 拖拽 | `drag`：起点→终点（元素引用 ∥ 坐标两形）真实序列（按下 → 移动×N → 抬起）；HTML5 拖放（`dispatchDragEvent` 形——可选支，设计定） |
| **F-BT12** | 触屏 | `touch`：点按（单/双点）∥ 捏合缩放 ∥ 滑动（手势级）；走触屏事件管线（参照 `Input.dispatchTouchEvent` / `synthesize*Gesture`） |
| **F-BT13** | 文本与 IME 插入 | `insert`：纯文本插入（不按键——长文本/emoji 路径）∥ IME 组合（候选写入 → 提交——形由设计定；参照 `Input.insertText` / `imeSetComposition`） |
| **F-BT14** | 输入基建（几何/滚动到视/聚焦） | snapshot 元素携**几何**（视口坐标/尺寸/视口外标记）；动作前自动**滚动到视** + 聚焦管理（视口外目标同样可驱——自动滚动实证） |
| **F-BT15** | 剪贴板保真读写（用户 14:51 令——原边界外项拉入） | 写：工具侧把指定文本写入**系统剪贴板** ∥ 页面内复制动作（Ctrl+C 类）**真达系统剪贴板**；读：读取系统剪贴板文本（回执）∥ 页面内粘贴（Ctrl+V 类）真取剪贴板内容；无头 ∥ 有头双支持；权限/授权路径 = CDP Browser 域或等价（设计定）；**真达**判据 = 端到端实证（工具写 ⇒ 系统读回 ∥ 系统写 ⇒ 工具读回——有头跑；无头 = 会话内剪贴板——设计档 §3.5 实测登记） |

**健壮性轮：无界等待归零 ∥ 外部关闭自愈 ∥ 异步通道 ∥ 用法认知（2026-10-07 19:4x——用户投诉/裁定/考题 · 主 agent 笔）**

| # | 需求 | 判定句（可机器验证） |
|---|---|---|
| **F-BT16** | 动作硬超时（有界不悬挂——用户 19:41 投诉） | 任一动作调用（含会话自启 ∥ CDP 命令 ∥ 轮询等待 ∥ 关闭路径）在硬预算内返回；超时 = 显式失败回执（携动作名与卡点步名）+ 可重试；**无任何动作路径可无界悬挂**（判据 = 挂死型假传输下逐动作于预算内拒绝；预算表 = 设计档 §2.9） |
| **F-BT17** | 会话外部关闭可感知与自愈（用户 19:46 更正） | 自启浏览器被外部关闭（进程退出 ∥ 连接断开）⇒ 在飞动作即时显式失败（不呆等）；后续调用干净重开（页面态丢失、profile/登录态保留，重开注记可见）；会话不因外部关闭进入中毒态（后续调用不再挂） |
| **F-BT18** | 异步通道（不阻塞回合——用户 19:41「我们这儿不都是异步的吗」） | 动作可后台执行：起跑 ack 即时返回；结算摘要可达（完成 ∥ 失败 ∥ 被杀三终态必达或显式确认）；`wait_for` 可等（条件 `browser id:N done`）；可杀（`process` kill） |
| **F-BT19** | 用法认知（描述面——用户 19:49 考题） | 工具描述含「现实环境实践」段：反爬墙/登录门识别 ∥ 动作节奏（连击降速、重取快照）∥ 会话假设（不假定自启浏览器常驻）∥ 弃用转路判据（静态面 ⇒ fetch；无需交互的链接 ⇒ 直接生成；需人工操作 ⇒ 请用户点） |

## 3. 非功能性需求

| # | 维度 | 标准 |
|---|---|---|
| **N-BT1** | 零第三方依赖 | 实现只 import `node:*` 与仓内模块（CDP 走 Node 原生 WebSocket；浏览器 = 系统已装 Edge/Chrome） |
| **N-BT2** | 内容按不可信数据 | 页面内容（snapshot/evaluate 回执）按**不可信外部数据**处理——注入指令不构成工具指令（沿 MCP 面纪律）；回执标注来源 URL |
| **N-BT3** | 输出规模可控 | snapshot/回执有默认规模上限 + 截断标记（防长页面淹上下文——上限值设计定）；evaluate 回执同受上限 |
| **N-BT4** | 隔离与凭据 | profile 与用户日常浏览器隔离；工具不读写用户浏览器数据；工具输出不泄漏 profile 内凭据（未见性面由设计定） |
| **N-BT5** | 平台面 | Win/mac/Linux 浏览器发现（Edge/Chrome 候选表 + env 覆盖——沿 `scripts/console-walkthrough.mjs` 实证表）；启动失败 ⇒ 可读的错误提示 |
| **N-BT6** | 可测试 | CDP 客户端与快照逻辑可对假传输单测；真浏览器冒烟（本机 Edge/Chrome 无头）纳入批内件 / 走查 |
| **N-BT7** | 写面门覆盖（新增动作） | 新动作写/读分类**逐动作机检表**（拟值：press ∥ mouse ∥ drag ∥ touch 点按 = 过门；hover ∥ wheel ∥ insert = 免审——判定表设计定稿）；过门 = **复用**既有审批机制（F-BT7——不建新门类）；拒绝 ⇒ 不执行且回执明示 |
| **N-BT8** | 兼容与不回归 | 既有八动作**对外语义**零回归（内部机制选型 = 设计）；新动作无头 ∥ 有头双支持；零第三方依赖保持；旧用例全绿 + 新动作逐条配用例 |
| **N-BT9** | 剪贴板隐私面 | 读写两侧**均过审批门**（拟值——剪贴板可携凭据；判定表设计定稿）∥ 读回执受输出上限约束（N-BT3 族）∥ 剪贴板内容不写日志 / 不落盘（形设计定） |
| **N-BT10** | 挂起可诊断（用户 19:41 投诉） | 超时失败回执含卡点步名；异步任务终态必达摘要（或显式取消确认）；**无静默悬挂 ∥ 无静默丢失** |

## 4. 范围边界（不做）

- **不做接管**（不连用户正在用的浏览器实例、不开发浏览器扩展、不做 WebView2/内嵌实例池）——用户 2026-10-07 13:10 明裁。
- 不做录制回放 / 工作流编排层（后议——真需求再立）。
- 不做全自动爬虫面（反爬规避 / 大规模并发抓取 / 自动凭据填充）。
- 不改 `web` / `websearch` 工具语义（静态抓取面照旧；本工具 = 其互补面，D2 各持权威）。
- 不引第三方浏览器自动化库（Playwright/Puppeteer 类——零依赖纪律）。
- 不建模型侧新机制（审批/权限沿既有机制消费，不新增门类）。
- **CDP 物理不可达面不做**（扩展轮边界）：浏览器外壳（地址栏 ∥ 原生右键菜单 ∥ 原生对话框）∥ 浏览器窗口之外的 OS 级动作。

## 5. 依赖与关联

- **上游依赖**：系统装有 Edge 或 Chrome（无 ⇒ 显式不可用）；Node ≥ 24（核宿主底线）。
- **下游关联**：工具注册面（四端——F-BT8）· 审批/权限机制（F-BT7 消费）· 走查/测试实践（本工具的副产品用途——非需求）。
- **先例参考**（不复制，D2）：`scripts/console-walkthrough.mjs`（CDP 直控 + 浏览器发现 + profile 隔离的**已实证**先例，2026-10-07）· thinworker 邻仓「浏览器控制」设计档（工作区只读参考——双通道全方案；其扩展直连面 = 本工具明确不做面）· openclaw browser 工具档（选择序 / 权限模型）。
