## 1. 总体定位

配置系统 = 装载器与默认值 **+** 迁移 **+** 分段配置 **+** 写盘面 / 设置面板 **+** `settings` 工具 **+** 路径展开 **+** 代理 **+** 供应商增删 / 密钥 / 激活。
两端**同一文件同一格式**——`~/.thincoder/config.json`（严格 `JSON.parse`，无 JSONC）。
本板块对本子系统的要求 = 该面归一为**核内单一装载器 + 全量默认值表**，且**键面变更保留兼容**。

> 面清单与逐面裁决（分类 / 端差处置 / 前提校验 / 归属段）→ `docs/core/design/CONFIG.md` §1–§2（不复制）。
