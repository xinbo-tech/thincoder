## 1. 总体定位

文案与本地化 = 文案容器（CLI 内联于源码字面量 ↔ VSC `thincoder-vscode/src/i18n.mjs` + `locales/{en,zh}.json`）。
**机器消费面（冻结）** = CLI `[error] ` 前缀 · ACP 通知文案 · VSC locale 逐字串。
本板块对本子系统的要求 = **容器归一 + 投影端差**（核内文案常量 + VSC 字典投影），机器消费面**冻结**。

> 面清单与逐面裁决（分类 / 端差处置 / 前提校验 / 归属段）→ `docs/core/design/I18N.md` §1–§2（不复制）。
