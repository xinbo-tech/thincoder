# Function Spec · M10 测试纪律

> 模块划分权威源 = `docs/core/design/ENGINEERING-MODE-V2.md` §2.2（M10）

## ① 模块目标

测试门禁**简化**：三层测试门（`test:full` + `test:integration` 等）→ **一条 `test` 全绿**（lint/check-syntax = 语法门，不在本模块砍单——2026-09-17 裁定窄读）。砍掉慢测层归册、多套脚本、测试退役台账——测试是开发期工具，不是库存。

## ② 功能点

1. **统一 `test` 命令**：一条命令跑全量，全绿即门禁。
2. **砍多套脚本**：`run-fast` / `run-full` / `run-integration` / `slow-gate` / `slow` 多脚本 → 收敛为一条。
3. **砍慢测层归册**：不再「归册到慢测层 + 快层 skip」——慢就慢，全量跑。
4. **砍测试退役台账**：不做「批次收口的测试退役三选一」流程。

> 具体裁剪到模块设计定；本规格只定「简化」方向与验收。

## ③ 边界（不做什么）

- 不做测试**内容**（各模块自己写自己的测试用例）。
- 不保留「三层门禁」语义（明确砍为一条）。
- 不引入新测试框架 / 依赖（零依赖不变）。

## ④ 验收（逐条可机判）

| # | 判据 | 方式 |
|---|---|---|
| AC-M10-1 | `npm test` 一条命令跑全量 | 跑命令 |
| AC-M10-2 | 无 `run-fast` / `run-full` / `slow-gate` 等多套脚本残留 | 检查 `package.json` scripts |
| AC-M10-3 | 无慢测层归册机制 | grep 无匹配 |
| AC-M10-4 | 全量测试全绿（门禁依据） | 跑命令 → 期望 exit 0 |

## ⑤ 依赖

- **上游**：M2（台账迁移破既有测试 fixture——被破测试的最小重写随 M2 实施批落地）。
- **下游**：无（终端门禁面）。
