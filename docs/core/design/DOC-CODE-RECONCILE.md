## 1. 定位与问题

设计 / 需求档的「事实句」会落后于代码与测试现态（同一类残量在排查中反复出现）。机检 V1–V4 管**形态**
（段引用可解析 / 计数与枚举 / 批档轮次 / 跨仓形态），**无一判「句子说的还是不是真的」**。

本板块补齐「**事实锚存在性**」这一判据（V5），并给它配**清账路径**与**防回潮装置**（反查脚本 + 人巡语义）。
定位边界：不改 V1–V4 既有判据语义；不承诺「无锚语义句」清零（机器判不了——归人巡）。

## 2. 方案选型对比（现行有效者）

| # | 候选方案 | 判据逐项评估 | 取舍（选定代价 / 权衡） | 结论 |
|---|---|---|---|---|
| 1 | **批次档不入 V5 源域** | 批次档 = 时序日志：其任务节写于实现前（用例号 / 路径**前指**是结构性的，不是漂移）；证据面 append-only、回改禁，§2 规范面可就地改 | 代价 = 批档内陈旧锚不由机检兜（改由反查 + 巡检兜） | **选定** |
| 2 | **A1 全形态 + 右界强制** | 本仓真实在册含裸形态（无前缀的用例号亦为标题）；右界断言使「短号不得由长号满足」（`T-VS3` 不得由 `T-VS32` 满足） | 代价 = 抽取式须带右界、范围书写须逐 token 拆 | **选定** |
| 3 | **A2 存在域 = 合并仓代码面** | 仅取本域时，对位叙述与跨面实装名成片假阳（「红一片 = 无人看」） | 代价 = 存在性判据读全仓代码树（域集并集） | **选定** |
| 4 | **注记必须携带消解信息** | 仅含「已废」二字即放行 = 变相豁免通道（破 F14 精神） | 代价 = 注记须带指针 / 删除记录 | **选定** |
| 5 | **判据单源复用** | A3 判序复用台账机检导出的同一函数；抽取器 V5 与反查共用一份 | 代价 = 判据宿主须与被复用档同处一包装根 | **选定** |

### 3.3 A1 用例号锚

- **抽取式**：`T` 前缀形 + 裸形，**右界强制**（`scripts/doc-check-anchors.mjs:46`）。
- **形态拆解**：范围 / 并列书写逐 token 独立抽——端点各自判，不作整体。
- **排除式**：① 前缀非 `T` 的内部编号（验收 / 需求 / 决策号族）不入（设计档内部编号 ≠ 用例号）；
  ② A1 形 token 不再入 A2 / A3（判型互斥）。
- **在册判据**：**认用例标题**——注册调用首参字面量标题含该 token（右界判）。「任一档含」不计：
  注释 / 清单 / 变量数组内的提及不构成在册。
- **假阴面（如实登记）**：被注释掉的注册行仍满足「标题含 token」⇒ 该形态漏报（注释语义机器判不了）；
  库存外的用例注册写法（如动态标题）出现时按判红处置（消解 = 把编号写回标题字面）。

### 3.4 A2 符号锚

- **抽取域**：行内反引号码段内的**单 token**。
- **强形态判据（须命中其一）**：小写→大写跃迁的驼峰 · 下划线前缀 · 蛇形命名 · 全大写常量 · 点径（判首段）——`scripts/doc-check-anchors.mjs`。
- **排除式（逐条）**（`:124`）：① 含 `/` 或带代码 / 文档后缀 ⇒ 归 A3；② token 为本域 `docs/` 树任一 `.md` 档名主干（派生排除，非词表）；
  ③ **平台 / 库 API 词表**（判据句：**不是本仓命名空间的名字，不属「本仓自建符号」的定义域**——**非豁免通道**；
  派生面三类 = Node 内置模块导出族 / DOM 接口 / 扩展宿主命名空间；载体 = 引擎导出常量，`scripts/doc-check-anchors.mjs`）；
  ④ 平台码形态；⑤ 通用词与字面量（长度 < 3 · 纯小写单词 · 布尔 / 空值字面量等）。
- **在册判据**：token（或点径首段）在**合并仓代码面**以**词界**命中 ⇒ 通过（`:191` 域集）。
- **假阴面（如实登记）**：在册判据读代码面全树 ⇒ 测试文件内以字面量驻留的**夹具名 / 旁注提及**同计「在册」——
  真仓清单可能被自我遮蔽。处置形态 = 夹具 / 引例名**不落字面量**（片段拼装书写），与 P4 互为镜像面。

### 3.5 A3 路径锚

- **抽取式**：码段内 ① 带目录段的路径 ② 裸 `.md` 档名；坐标尾 = `:行号` / `:行号-行号` / **并列组**（`/` 分隔 1..n 组，如 `:54/:103`）——**整段尾不参与**存在性判（形态闭枚举与射程边界见 `docs/core/design/DOC-DISCIPLINE.md` §4.2.1 与 §3.5；载体 `scripts/doc-check-anchors.mjs:45`——`PATH_RE` 整段消费坐标尾）。
- **排除式（逐条）**（`:138`）：① 首段为非仓档坐标（父目录 / 用户态 / 工具面点目录 / 依赖面）；② 首段为任一产品域目录名（域前缀）；
  ③ 同行带节号且 token 为 `.md` ⇒ **归 V1**（不重复报行——非 `.md` 路径 token 照判）；④ token 后紧跟「（…域）」注记 = 合规域别形态；
  ⑤ 通配 / 角括号占位（命名约定与模板引例——出现即排除、无名单、非逐项豁免）与示例占位段名；⑥ 首段以 `-` 开头（并列斜杠书写伪影）。
- **存在性判序**（与台账机检同源，不发明第二套定位语义）：仓根直接解析 → 陈旧 / 省略前缀（首段须为仓根现存条目且 basename 域内唯一）→
  裸 `.md` 档名（本域现态面命中）→ basename 多义 ⇒ 判（不可定位，须带目录前缀）→ 零命中 ⇒ 判（不存在）。

### 3.6 注记识别形态（判据的「已消解」通道）

**判据句**：注记**必须携带消解信息**——仅含「已废」二字**不构成通过**（防注记滥用 = 变相豁免）。实现 = `scripts/doc-check-anchors.mjs:249`（注记标记集判定）。

| # | 形态 | 判据 |
|---|---|---|
| **N-1** | 退场注记 | 退场词 + 同行携带消解信息（删除记录指针 / 批名形态 / 来源坐标 / 现体指针） |
| **N-2** | 迁移 / 归位注记 | 归位 / 迁移词 + 同行携带指针（`.md` 或 `文件:行`） |
| **N-3** | 对照引述 | 反引号切断档名后缀与节号的连续书写——连续书写即命中（**不是豁免**） |
| **N-4** | 夹具 / 引例注记 | 夹具 / 引例词 + 同行携带用途（合成缺失 / 零报样例 / 清账对象名录等） |

### 3.8 两态与计数口径

| 态 | 行为 | 退出码 |
|---|---|---|
| **报告态**（默认，VSC 锚引擎） | 输出逐处行 + 尾行计数 + 机读清单；**不阻断** | `0` |
| **阻断态**（阈值 0） | 命中即红 + FAIL 句 | `1` |

- **切换**由参数驱动（CLI 锚：`--v5-gate` / `--v5-report`；VSC 锚：`--strict` / 环境开关）——判定函数接受显式 gate 参数（两态可直驱，用例跨切换点零改）。
- **计数口径（固定）**：命中**处数**（逐处，同 token 多处多计）+ **distinct**（去重 token 数）+ **分型**（A1 / A2 / A3）。
- **基线通道不存在**——本检查器不读也不写任何基线档（不是「默认空」，是通道不存在——阈值 0 的对应实现）。
- **射程边界（不重复报行）**：带节号的 `.md` 引用归 V1 面；台账条目归 L1–L4 专判；批次档与归档不入源域。

|---|---|

| **E-2** | **外部参照面**内的锚（符号 / 路径 / 用例号）**一律出射程**——判据句 = 该面断言的对象**不在本仓命名空间**，存在性无可判面（与「示例占位 / 通配形态」判据同族：**不指向本仓现态档件**） |


**两态与计数口径（承 §3.8）**：默认**报告态**（外部参照面计数 = E-3 独立计数 · 不入阈值）；`--strict` 下**阻断态**（阈值 0——命中即红）。
VSC 域锚检对产品树外部符号现以**报告态**输出（非阻断——口径依据见 `docs/vsc/design/VSC-MIGRATION.md` §2.4 产品树降格声明）。

## 5. 语义巡检机制

| 项 | 判据 |
|---|---|
| **归属** | 该板块的**归属者**（设计档板主）——批收口时由父侧指派对位；无归属者 = 巡检未执行（判据 = 记录行缺名） |
| **周期** | ① 每批收口一次（强周期）② 轮巡（每 10 批或 90 天，先到者）③ 事件触发（机检 / 反查命中、撞见即清） |
| **记录形态** | 批次档收口行的「语义巡检」小节（范围 / 发现数 / 处置）；未处置项转技术待办（带触发）；**不新建活动台账**（单一权威源） |
| **不承诺** | 只承诺**有归属、有周期、有记录**——不承诺无锚语义句清零 |
| **抽查方法（人判）** | 抽样陈述现态的事实句 → 找不到锚的句子为候选 → 逐句问「代码 / 测试现在还是这样吗」→ 不是则按 §3.6 形态处置 |

### 5.1 关键决策记录

| # | 决策 | 理由 |
|---|---|---|
| D-DR9 | 层 0「先重锚」为对账**前置步**（先定权威副本，再谈漂移） | 不重锚即对账 ⇒ 对参照历史面产生改笔，制造维护负债 |
