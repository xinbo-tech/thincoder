### 2.2 #175 · memory sweep（命令面 + 安全设计）

- **判据面已在位**（`MEMORY.md` §6.13）：写入面归一化强制（`normalizeOrigin` 唯一归一函数——`thincoder-core/memory/origin.mjs:18-24`）；死 origin sweep 二信号（A = `normalizeOrigin(o) !== o` ⇒ 折叠不删；B = `!existsSync(o) ∧ !existsSync(normalizeOrigin(o))` ⇒ 可删；仅 ENOENT 判亡，其余 fail-safe 保留）。
- **本批新增 = 命令面**：`thincoder memory sweep [--origin <o>] [--dry-run|--confirm]`——核新档 `thincoder-core/memory/sweep.mjs` + `thincoder-cli/src/cli/memory-command.mjs` 新子命令；`--origin` = **origin 级 purge**（台账所称缺位面：现有删除面仅文件级 `origin=? AND path=?`）；缺省 = 全扫。调用面 = CLI shell 子命令（VSC 无 shell 子命令面——结构性端差登记见 `MEMORY.md` §2.2 #135）。
- **安全设计（三件）**：① **备份前置** = `VACUUM INTO <path>`（判据同 §6.11 步 1：存在 ∧ 大小 > 0 ∧ `PRAGMA integrity_check` = `ok`；失败 ⇒ 中止零写）；② **干跑默认**（`--confirm` 才写；dry-run 输出 = 逐 origin 动作 + 行数，零写判据 = 库字节 / 行数不变）；③ **审计** = 逐 origin 折叠映射 / 删除行数 / 备份路径 + 写后回读判据（归一键集合 = 1 ∧ 唯一行 ∧ `COUNT(*)` ≤ 前——同 §6.11 步 3）。
- **折叠规则单源 = §6.11 步 2**（同归一键内 `(path, line_start)`（`files` = `(layer, path)`）恰一行——保留 `mtime_ms` 最大者，并列取 `rowid` 最小者；FTS 触发器随行同步）：sweep 不另立规则。
- **执行分工**：真实库写 = **父侧 ops**（承 §6.11 迁移面纪律「子代理零触碰」：备份 → dry-run 复核 → `--confirm`）；实现轮只落工具 + 沙箱用例 + 干跑读数（只读）。
