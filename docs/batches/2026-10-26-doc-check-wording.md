**发现的真 bug（顺手修了）**

`index.mjs` report 态的统计与 `scripts/doc-check.mjs` 的过滤，都写着字面 `h.clazz === "段太长"`。clazz 一改名，这两处会永远数到 0——报面显示「0 段」，实际有命中。修法 = 类名收成 `DOC_CLASS` 常量单源，两处取其值，不再各写字面。

**父侧直改设计档的记账**

`DOC-DISCIPLINE.md` 按 D1 归设计席的笔。本批父侧直改，理由 = 用户 11:24「盯着点」「子agent 又自说自话」——同一批措辞改动派子代理有再次变形的风险。改动面 = 类名字面统一 + 两处「拆段/写短」回正，不动判据算法与阈值。

**进程内旧模块（重要，非缺陷）**

当前会话的 `doc_check` 工具在进程启动时已 `import` 了旧模块，磁盘改了它看不见——工具输出仍是旧措辞，**重启后生效**。本批的新代码验证一律走独立脚本（`node` 新进程），不走会话内工具。
