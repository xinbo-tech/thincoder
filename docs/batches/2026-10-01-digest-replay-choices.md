**三、统一方向 = 全量重放（未结轮照现）——三端同判**

**语义（五条——跨端单源；落点见「十」）：**

1. **轮锚 = 起跑记录**：`digest` 记录逐条复列；起跑记录在位 ⇒ 该轮出（起跑行/元素 + `n > 0` 计数行/元素；`cap` 记录在位 ⇒ cap 行/元素；`end` 记录在位 ⇒ 终态行/元素）。
2. **未结轮照现**（本批收口）：无 `end` 记录之轮 ⇒ **照出已有记录**（起跑 ∥ 计数 ∥ cap）——不产终态。判定面 = **可证**：轮间（后轮起跑已现 ⇒ 前轮未结——轮序单链）∥ 末页（**扫描结束仍 `open`**——跨非 digest 记录存续，`end` 若在必在页内——尾残轮）。
3. **跨页截断面 = 容差① 维持**：起跑未载的 `cap` ∥ `end` 记录零产（防并轮错位）；**非末页的尾残起跑不入产出**（可能为他页完整轮之半——不可证）；CLI = 消（逐条复列 + 存储回扫）；重开条件 = 实测走查命中 ⇒ 另批跨页承接。
4. **`n = 0` 守句**（同拍）：`n = 0`（ask-only）⇒ 零计数行/元素 ∥ **零终态行/元素**（禁幻影行——三端同守；桌面补设）。
5. **位次门**（桌面 · #773）：折叠轮必携位次（`at` = 起跑记录全局 `idx`）；`at` 不可得 ⇒ 该轮**零产**（fail-closed ⇒ 折叠面无 `at = null` 轮 ⇒ `liveSegment` 判据恒成立）。

**三端落点**：CLI = **零产品码**（照现 + 守句俱已在位；本批只收正设计句「沿现行口径」⇒ 统一口径）∥ 桌面 = `foldDigest` 开出未结轮（可证面）+ 位次门 ∥ 未结轮归属（并入点——活流侧优先，修复轮 1 钉）+ `digestRows` 守句 ∥ VSC = `scanPageRounds` ∥ `restoreRecordEls` 扩面（起跑/cap 随轮出；终态仍赖 `n`——同页起跑）。

**桌面归属规则（防双份——结构性 · 活流侧优先；修复轮 1 · 2026-10-01 收正）**：首屏径——运行期未结轮在场（`clearDigest` 未结末轮保后非空）⇒ **折叠未结末轮不并入**（唯一副本 = 运行期轮——其帧更新存续：`cap` ∥ `end` 恒得末轮）∥ 运行期未结轮缺（含重开径）⇒ 折叠未结末轮照并入（照现）；**零跨侧去重键**（`at` 只随折叠轮侧）——**同轮 ∥ 异轮不可判**，所失面 = 异轮 + 活轮记录未及投影窗：旧未结轮暂不并入（随后续落盘投影、下次首屏复现）。正确性论证 = 页窗连续后缀（起跑在窗 ⇒ 其后记录皆在窗）∥ 轮序单链——运行期未结轮 = 会话末轮；**活轮不变式** = 运行期未结轮跨首屏页读恒存续（清点只及终态轮）。

**为什么是这个方向（判由）**：① 「恢复序 ≡ 记录序」判据句（`RENDERER.md` §1.1 ④——记录 = 唯一参照）：重放 = 逐记录复列；过滤 = 在重放面加截点（CLI 端刚立「零截点」）；② 桌面/VSC 现行排除 = **机械原因**（防双份 ∥ 页配对 `n` 源），非语义需求——机械因由本批结构性消解；③ **保留须宿主能力证据——不适用**（无宿主能力差：三端同持记录；排除系实现机械）；④ 落点量级 = 桌面/VSC 去排除（小改）∥ CLI 零改；反向（完整轮专出）= CLI 加完整轮过滤——跨页歧义不可判（CLI 单页无全局终局知识 ⇒ 前向扫描 = 造机），被否。
