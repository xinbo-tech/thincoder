**二、设计定形（五项逐条：现状 → 目标 + 判据）**

**① 记录粒度**
- **痕 = 逐事件记录（`kind: "digest"`，三型）**：`{ status: "start", n, tier, from?, msg? }` ∥ `{ status: "cap", mode, turns }` ∥ `{ status: "end", ok, ms }`，逐条并 `ts`——**与 `ev:digest` 三形一一映射**（零新语义，单一映射）。⇒ **痕族三行（起跑标签行 ∥ `n > 0` 计数行 ∥ cap 行）全套可重建**（读面折叠 = 归约面 `onDigest` 同式复用——单一实现）；**不取「仅起跑行」**（cap ∥ 终态事实不可弃——「几段分不清」正靠三行解）。
- **块体 = 一块一条快照记录（`kind: "subagent"`）**：`{ meta, rows }`——`meta` = 归档时点头行事实（现 `archiveIntoFlow` 快照形逐字：`thincoder-desktop/renderer/subagent-reduce.mjs:93-112`）；`rows` = 内容行集**有界保尾**（上界沿核件尾环既有一致口径——先例 = CLI N2 500 行/子，`thincoder-cli/src/tui/tui-state.mjs:40`；超界 ⇒ 保尾截断，**明示**）。⇒ 折叠面（头 + tail-3）与展开面数据俱在；**不取「仅头行」**（头行孤块 = 伪在场）。

**② 入档形（会话数据面）+ 六型域 ∥ 页读域边界重划**
- **形 = 会话人读线（`history`）记录直通型两族**——复用会话数据面**既有形**：记录 = 人读线条目（与消息同流同序；追加走 `pushReal` 同面——核 `thincoder-core/context.mjs:93-101`；记录不在 `agent.history` ⇒ **机器线零触**——不喂模型；判据 = `contextHistory` 零新增条目）。
- **边界重划**：
  - `subagent` 块由「运行期块」（`docs/desktop/design/UI.md:18` 五项页读域之外）**升入页读域** ⇒ **六型域全员入页读域**（「运行期块」术语退场 ⇒ **留档块**）；其三条旧账**退场**：退窗即弃 ∥ 不计 `data-hidden` ∥ 不成回填对象（`docs/desktop/design/RENDERER.md:130`）——留档后计 `data-hidden` ∥ 可回填 ∥ 退窗折摘要块。
  - 消化痕 `[data-digest]` **仍非块节点**（零 `data-block-id` ∥ 不占块序 ∥ 不计 `data-blocks`——**不变式保持**）；新增**页读重建**面（记录直通 + 读面折叠 ⇒ 痕元素按记录位次流内就地重建）。
- **写面（记录产生面直追加——单源）**：
  - ① digest 三型 = **宿主直追加**——与 `ev:digest` 发帧**同点双动作**（start ∥ end = `thincoder-desktop/src/main/suspension-drive.mjs` 发帧点；cap = `thincoder-desktop/src/main/turn-face.mjs:122`）；**零新通道**。
  - ② subagent 快照 = **渲染面归档派生点**（`archiveIntoFlow` 输出；**含非活动键**——一并取宽，消既有「非活动键内容即失」端差）经**新请求通道 `record:append`**（白名单 **45 ⇒ 46**）落宿主 ⇒ 宿主以 `pushReal` 同面入档。
  - 其余端 = 各端进程内同点追加（本批不实施）。
- **读面**：核 `thincoder-core/history-window.mjs` 增**记录直通（opt-in）**——`historyWindow(history, before, pageSize, { records: true })` 两型记录原样入窗（携 `idx`，字段零改名；`kindOf` 认 `kind` 键）；**默认关 ⇒ CLI ∥ VSC 读面零改零破**（对齐实现 = 其板义务——§七 U1）。桌面 `pageHistory` 开直通 ⇒ 页读回执 `messages` 携记录；`blockOfMessage`（`thincoder-desktop/renderer/page-read.mjs:65-83`）增 `subagent` 记录 ⇒ 留档块（**与活流归档同一形状**——单源）；`digest` 记录不进块面（归痕面折叠）。

**③ 重载 ∥ 回放 ∥ 跨会话存续**
- **落盘节律 = 与消息同节律**：记录追加进人读线段（即时可得）；槽文件投影 = 回合尾 `saveSession`（核既有，`thincoder-core/session.mjs:110-173`）⇒ 重载可见性 = 至最后一次落盘（**不新造即时落盘面**——单写者纪律零破）。
- **重载（webview reload）** = 页读首屏 ⇒ 记录重建（痕 + 块随至）✓。**回放（重建 ∕ 重挂径）** = 同源（记录位次）——**§10 CR 行「消化行族复聚流尾」随本批消解**（重建径改按记录序回放，置位规则与活流**同一套**：`digestBoundaryOf` 守卫 ∥ `blockAnchor` 两径复用；压缩行半句留观）。**跨会话存续（切走切回 ∥ 另开会话返回）** = 页读 ✓。
- `clearDigest` 切片清点**保留不变**（终态轮清切片）；痕面由此新增记录重建径 ⇒ 终态痕首屏后仍在场（由记录承接）；未结末轮 = 运行期切片承接（**记录折叠只产终态轮**——末轮无 end 不产，防双份）。

**④ 不变式兼容（逐点定形）**
- 痕（保持非块）：零 `data-block-id` ∥ 不占块序 ∥ 不计 `data-blocks`；**在场面 = 其记录位次落于已渲染块区**（随窗：头部淘汰 ⇒ 同拍摘除越位痕；回填 ⇒ 按记录位次重建——判据 = 记录位次，单源 = 读面）。
- 块体（subagent）：**占块序（现状保持）**；计 `data-blocks` ∥ 计 `data-hidden` ∥ 可回填 ∥ 退窗折摘要块。归档块落点守卫（#720 收正）**不变**——两径皆落块序尾位 ⇒ `DOM ≡ visible` 不变式与对齐步零改（重建径同规则复现）。
- 机器线零触（记录不入 `agent.history` ∥ `contextHistory`）。

**⑤ 跨端面（实读对位）**
- 共享源一条：**消化生命周期面 = 人读线记录**；恢复 = 各端从记录重建（本设计 = 单源）。
- VSC：需求 **F-W1**（`docs/vsc/requirements/WEBVIEW.md:20`）「终态消化回收后归档落流（消息区，形态不变）」= live 归档语义——**零变**；**I-7**（同档 `:75`「不做子代理块跨 reload 恢复」）= 其恢复面现状 ⇒ 对齐义务（录报）。
- CLI：digest 行 = `pushLine` 瞬态（`thincoder-cli/src/tui/suspension-drive.mjs:90-100` 实读）· `subTasks` = 内存态（`thincoder-cli/src/tui/tui-state.mjs:40`）⇒ 恢复零痕零块 = 现状；对齐义务同。
- 本批实施面 = 桌面 + 核（记录直通缝）；CLI ∥ VSC 恢复呈现 = 跨端对齐义务——承接见 §七 U1（**不可登记保留**）。
