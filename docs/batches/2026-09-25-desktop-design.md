### 1.4 已定硬约束（设计须遵守，来自需求档与用户裁定）

- **单项目 + 项目内多会话**；多项目并行 = 开多实例（核已有跨实例协作面）。
- **三平台**（Windows / macOS / Linux）从第一天即目标 ⇒ 打包链与 CI 矩阵同在设计面。
- **宿主 = Electron**（宿主平台口径，随发行物分发；体积 / 供应链 / 三平台打包链成本落本端发行面）。
- **前端本端自持、零框架手写**（纯 DOM + 浏览器原生）——不复用扩展端 Webview 代码；不引入非宿主的第三方运行期依赖。
- **不做**：文件视图 / 编辑器 / 内置 diff / 终端面板 / 常驻多项目面板 / 常驻全局活动栏；**活动池随会话**入标签页（形态见 `docs/desktop/requirements/PROJECT.md` §3）。
- **共享契约**：与 CLI / 扩展端读写同一份 `~/.thincoder/config.json` 与 `~/.thincoder/sessions/`（C1 / C2）；不得另立存储格式。
