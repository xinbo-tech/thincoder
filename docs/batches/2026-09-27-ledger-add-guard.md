### 2.2 机制设计（摘要——全文 = 设计档 §3.2）

- **落点 = 工具层 `execute`**（`thincoder-core/ledger-cmd.mjs` 三处；守卫 helper 同档单点）：判序 = 参数守卫 →（核内）迁移表判 → 写门 → UPDATE ⇒ 拒绝时**零写、零库动作**（判于 `openLedger` 之前）。
- **机制 = 声明派生（单源）**：守卫消费工具自身 `parameters`（`required` / `type` / `enum`）——不在守卫内复写字段表；同批声明收正 = `ledger_update.status` 补 `enum`（六态）+ 三写工具补 `additionalProperties: false`。
- **判序**：① 入参缺省 / `null` ⇒ 视作 `{}`；非对象 ⇒ 拒（P1）② 未知键 ⇒ 拒（P2）③ 逐字段（声明序）：缺失 ⇒ 拒（P3）→ 类型 / 枚举 ⇒ 拒（P4 / P5）→ `title` 空串 / 全空白 ⇒ 拒（P6——两工具同拒）；**字段级 `null` 归属**：必填 ⇒ 按缺失判（P3）/ 可空 ⇒ 放行。
- **文案模板（逐字；前缀 = 工具名`：`；`<预览>` = `JSON.stringify(值)`（>80 字符截断 + `…`））**：
  - P1 `<工具>：参数须为对象（收到 <预览>）`
  - P2 `<工具>：未知参数：<键…>（可用参数 = <可用集…>）`
  - P3 `<工具>：<字段> 缺失（必填<；取值 ∈ {…} | ；非空字符串>）`
  - P4 `<工具>：<字段> 非法：<预览>（应为字符串 / 数字）`
  - P5 `<工具>：<字段> 非法：<预览>（取值 ∈ {…}）`
  - P6 `<工具>：<字段> 为空（必填；非空字符串）`
- **逐字段判据表**（域 = 声明面；全文表 = 设计档 §3.2）：
  - `ledger_add`：`kind` 必填 · ∈ {requirement, tech_todo}；`title` 必填 · 非空串；`board` / `req_doc` / `task_book` / `evidence` 可空 · 串；`trigger` 可空 · ∈ {归批, 条件, 认账不排期}。
  - `ledger_update`：`id` 必填 · 数字；`status` 可空 · 六态；`title` 可空 · 串（**值非空串**）；`board` / `req_doc` / `task_book` / `evidence` / `executor` 可空 · 串；`trigger` 可空 · 三枚举。
  - `ledger_close`：`id` 必填 · 数字；`status` 必填 · ∈ {已核销, 已废弃}。
  - 三工具 `cwd` 均「可空 · 串」（`cwd 非法：<v>（应为字符串）`）。
- **探针实读 A（绑定 / CHECK 族——tmp 目录 · 零仓写 · 2026-09-27）**：`kind` 缺失 ⇒ `Provided value cannot be bound to SQLite parameter 1.`；数组入参 ⇒ `Unknown named parameter '0'`；`kind` 非枚举 ⇒ `CHECK constraint failed: kind IN ('requirement','tech_todo')`；`在途` + 空串 `task_book` ⇒ `CHECK constraint failed: status NOT IN (…) OR (task_book IS NOT NULL AND task_book <> '')`。
- **探针实读 B（静默 / 毛刺族）**：空 `title` ⇒ 静默入账；未知键 ⇒ 静默忽略；`id: "1"` ⇒ 静默命中（真更新）；`id: []` ⇒ `ledgerUpdate：行  不存在`（毛刺）；入参 `null` / `cwd` 数字 ⇒ 英文 TypeError；复杂文本（引号 / 反引号 / `file:line`）⇒ 现状即写通（回归基线）。

### 2.6 关键决策

- **守卫落点 = 工具层 `execute`**（父侧定调 + 设计确认）：原始 args（含未知键）只在工具层存在——未知键闭合只可在此表达；核函数保持数据语义。落选（被拒）= 核函数层守卫（写门同层）——写门守数据不变量、参数守卫守模型调用契约。
- **未知键 = 拒**（非忽略）：取舍——「不理会」= 打错键静默丢字段（半写 / 无写无感）；「拒」= fail-closed + 修向文案（本仓口径）。
