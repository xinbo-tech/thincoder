- 补偿 = 帧尾既有补偿纪律**新消费方**：只计**视口顶锚之上的净高变化**——挂（锚上）⇒ `scrollTop += h`；卸（锚上）⇒ `scrollTop -= h`（**先读后卸**）；
  锚下变更零补偿；读 ∥ 写分拍批量（读齐后写；写后复读仅补偿路径）。
- 跟滚帧**零读**：底窗直取（末段起）+ 变更后重写贴底超值（`stickToBottom`——防挂载段把视口从底顶开）。
- 执行点 = **帧尾第 ⑦ 步**（`settleFrame` 六步**之后**——独立显式补偿 ∥ 与 [t0, t1] 区间互不叠算）；
  触发 = 内容帧尾 ∥ 滚动拍（`onScrollTick` ⇒ `frame.mark(["segView"])`——`segView` = 哨兵键非切片；帧合并节流 ≥50ms ⇒ ≤20 拍 ∕ 秒）。
- 单权源保持：`overflow-anchor: none`（现行 `RENDERER.md:147`）不动——段窗 = 新消费方，非新锚定源。
- 与回填：前插（headMoves）与段窗**互不叠算**（各担己量——定序 = 六步 → 第 ⑦ 步）；回填触发（顶 ≤40px）判据零改。

**③ 文本等价门**（三判；**不可达 ⇒ 该形弃**）：
- G1 全量在场：窗口态 ∥ 全挂态 `face.textContent` ≡ 核 md 产出文本（巨块 fixture = 源串 606,208 字符逐字；差 = 0）——**窗口态即可跑**（探针 census 面复用——无「先滚到底」前置）。
