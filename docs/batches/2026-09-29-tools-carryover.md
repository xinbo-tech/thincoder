#### 2.1.2 候选三形与取舍（父侧点名）

| 形 | 机制面 | 送达面 | 长驻（服务器）用例 | 口径一致度 | 判 |
|---|---|---|---|---|---|
| A 真后台进程 | detached + stdio→log + 返 pid/路径 | **无**（须轮询/read） | 可（天然跨会话） | 低（违 settle 口径） | 否 |
| B 任务池 | `async` 起跑 → 分域池条目 | settle → digest 注入 | 可（不 settle 不阻塞、可杀） | **高**（全沿 consult ∥ escalate 族） | **择** |
| C 会话挂起 | 同步跑 + 会话挂起 + 唤醒注入 | 有（唤醒注入） | **否——永不 settle ⇒ 挂起钉死** | 中（无 ack 面） | 否 |

- **择 B —— 由**：① 批档边界硬要求「与 consult ∥ escalate 异步面口径统一（不另立体系）」——B 的起跑 ack ∕ 分域池 ∕ settle 送达 ∕ 墓碑 ∕ 帽全沿既有族；② 长驻用例由「不等待 + 随时查 + 可杀」覆盖；③ C 的「永不 settle ⇒ 会话钉在挂起态」无解；④ A 无送达面 ⇒ 取用成本反升（轮询回合）。
- **被否登记**：A（送达面缺 + 孤儿管理无主）· C（长驻钉死 + 无 ack 面）。

#### 2.1.3 机制设计（B 展开——接口契约）

- **起跑**：`bash` 参数面 + `async: boolean`（可选；缺省 false = 现行同步径**逐字零变**）——async 键 + `timeout` ∥ `filter` 两描述消歧（消「async/120s」与「filter」歧义；与 D9-3 ∥ 评审 #3 同旨）；形 = `bash { command, async: true }`。前置两件同保留（`gitGuardSnapshot` `bash.mjs:85-99` ∥ `posixSyntaxHint` `:28-38`）；审批 = 起跑即走既有权限门（同同步径——spawn 前核准）。
- **ack（工具返字符串）**：`bash#<id> started (running) — log: <logPath>`（id 取号沿两池共用命名空间先例——`AGENT-LOOP-ASYNC-POOL.md:120`「两池共用 nextSubagentId 命名空间」；`bash#N` 前缀区分域）。
- **池**：新分域池 `_bgTasks`（模式照 `_asyncAdvisors`——独立池 + 载体字段登记（`carrierField` 吸收族）+ 条目 `{id, command, child, logPath, done:false, status:"running", startedAt}`）；新档 `thincoder-core/agent-tools/bash-async.mjs` 承载池面单点（起跑 ∥ 结算 ∥ 杀 ∥ 清点——档面先例 = `async-discard.mjs` ∥ `advisor-async.mjs`）。
- **输出面**：全量流式落盘 `configDir/tool-results/<ts>-bash-<id>.log`（同目录 + 轮转复用——`agent-tools/digest-budget.mjs:64-76` `persistOverflowReport` 亲族 ∥ `cleanupOldToolResults`）；内存侧尾部环形缓冲（注入用）。ack 携 log 路径；运行中取件 = `read`（offset/limit）。
- **送达（settle）**：进程退出/被杀 ⇒ 结算 ⇒ digest 注入单点族（`pushReal` + `[System reminder: …]`）：**状态行**（命令 ∥ 退出码/被杀 ∥ 耗时 ∥ log 路径）+ **尾部**（≤120 行 ∧ ≤8KB 双帽 + 截尾注记）；全量恒在 log（注入即尾截——不经预算 offload）。
- **等待面**：`wait_for` 条件族 +`bash id:N done`（判据同式 `subagent id:N done`——池内 done ∥ 出池即 done；`ops.mjs:136-147` ∥ `:165-171`）。
- **终止面**：`process` 工具 + `kill` action（靶 = `pid` ∥ `id` 二选一）：pid ⇒ `killProcessTree` 同款；id ⇒ 池条目杀树 + 出池 + 墓碑（`writeTombstone` 语义）；重复 = 幂等；审批 = 破坏性同径。`tool-docs` 两处文本（`process.md:10`「kill 走 bash taskkill」欠面 ∥ `wait_for.md:4-9` 条件枚举）随 #15 轮（父侧笔）落。
- **超时语义**：async 起跑**不收默认 120s**（长任务 = 本形目的）；显式 `timeout` 仍生效（到点杀树 + settle 状态 `killed: timeout`）；同步径默认 120s 照旧。**同档同步改写面（评审 #3）**：现档 §6.4 命令行「bash 超时 120s」（`TOOLS.md:194`）随本批补限定（「同步缺省 120s ∥ 异步缺省无超时（→ §6.19）」——消同档两处对同机制互斥）。
- **收尾语义（两档——评审 #8）**：
  - ① **回合中断（Ctrl+I 停回合续跑）⇒ 不杀**——bg 任务存活留池（F2 同款豁免：`CONSULTATION.md:199`「interrupt 不逐链中止在飞会诊」；后续经 `wait_for` ∥ settle 消费）。
  - ② **会话中止（Ctrl+C ∥ Stop 全停）⇒ 逐条杀树 + 出池 + 墓碑**（D-CO4 同规则：`CONSULTATION.md:210`「仅 Ctrl+C / 会话中止时 abort（与 async 子代理同规则）」；杀树动作并经 discard 收尾面——沿「只清已死」单不变量（`async-discard.mjs:11`）：杀 ⟺ 控制器已中止）。**跨会话存活 = 不做**（边界——会话结束即清）。
- **帽**：`BG_TASK_MAX = 4`（对齐 `ASYNC_POOL_LIMITS` 单域 4；`AGENT-LOOP-ASYNC-POOL.md:84`）；超限**显式拒**（不静默——沿 timer 帽 ∥ 队满先例）。
