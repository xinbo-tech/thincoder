### 2.3 机制设计（六问逐答——对批档 §1 任务书问面）

**① 联动机制**：三件套 = 自动检测 + 显式切换 + 记忆。检测 = `localStorage["tc_lang"]` 优先（合法值 zh/en）；无 ⇒ `navigator.languages` 顺序扫描首命中（`zh*` ⇒ zh ∥ `en*` ⇒ en）；无命中 ⇒ **缺省 zh**（论证 = 现状保持零惊群——现全中文；内网团队母语中文；显式切换一触可达——如用户要 en 缺省 = 单常数改，披露①）。记忆 = `localStorage`（非 cookie——页面无 SSR 面，cookie 零收益且随请求）；切换器 = 「中文 ∥ English」双钮（当前态高亮），挂点（IA 服从 KD-SV-20）= 侧栏 meta 槽（登录后七页全达）+ 登录卡（`#/login` 无侧栏——未登录可切）；切换动作 = 写存 + 重渲（侧栏/视图同拍——重渲口 = `app.mjs` 的 `rerender()`）+ `documentElement.lang` 随动（zh-CN ∥ en）；表单草稿不保（低频——在案）。

**② 文案表形态**：**前端静态表**——三档 `i18n.mjs`（运行时）∥ `i18n-zh.mjs` ∥ `i18n-en.mjs`（数据；平铺点分键 + `Object.freeze`）；取载 = 静态 ESM `import`（浏览器原生——零构建 ∥ 零 fetch ∥ 零打包器；两语常驻内存——体量小）。键形 = `页面.区块.词`（`login.submit` ∥ `nav.page.me.keys` ∥ `err.<code>`）；参数 = `{name}` 占位 + `t(key, params)`；缺键回退链 = 当前表 → 中文表 → 键原文 + `console.warn`（安全网——批内件断言两表键集相等 ⇒ 回退不可达）。被否：后端下发（新端点 + 协商/缓存面——零收益）∥ JSON + fetch（异步多一跳）∥ 单档内联（破 300 软线）。

**③ 后端 API 错误策略**：**错误码 + 前端映射**（服务端零改——消息维持中文；口径行 = `gateway/API.md` §3 新增）。控制台按 `code` 映射 `err.<code>`——映射集 = 控制台可达码全集八枚（`unauthorized ∥ invalid_credentials ∥ forbidden ∥ not_found ∥ invalid_request_error ∥ upstream_error ∥ internal_error ∥ too_many_attempts`）；动态值 = `Retry-After` 头（`429` ⇒ 秒数注入——`app.mjs` 捕捉进 error）；参数码（`invalid_request_error ∥ not_found`）句末附服务端原文（细节不丢——en 下附注为中文，披露②）；码未在表 ⇒ 服务端原文兜底（新码/上游透传零遗漏；`quota_exceeded` 等 /v1 面码控制台不可达——不加行）。被否：双语字段（30+ 抛出点双语维护 ∥ 上游透传面无处双语）∥ 服务端消息改英文（CLI/curl 既有中文口径破坏）。

**④ 覆盖范围**：七页全量 + 登录 + 侧栏（品牌/组/页/退出/meta 槽）+ 表单（label/placeholder/按钮）+ 表头 + 空态 + 一次性秘密区（参数化句）∥ confirm ∥ flash ∥ 错误映射 ∥ 格式化助手（`fmtQuota`「不限」键化 ∥ `fmtTs` locale 随语言 ∥ `fmtValue`「—」中性保留）+ 标签页 title；挂点收编 = `nav.mjs` `label` ⇒ `labelKey`（单源保持）。不含：服务端日志/消息 ∥ README ∥ 用户数据值。

**⑤ 验收与用例面**：AC-14 候补判据 = §2.5；批内件 = §2.4。

**⑥ 与 #963 交界（同系统页——避免打架）**：系统页（`#/admin/system` 两节 + meta 槽版本行）= #963 面——本批只做文案收编（键引用；其设计已预注「收编时结构零动」）；数据源 `/api/system`、更新提示判据、meta 槽结构零动——零打架。
