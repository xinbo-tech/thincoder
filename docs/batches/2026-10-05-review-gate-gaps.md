- **判据函数（新导出；宿主同档——常量 `NO_VALID_ECHO_MARK` 族邻位；逐字）**：

```js
const VERDICT_PASS_LINE    = /^[ \t]*[*_`]*[ \t]*VERDICT:[ \t]*pass[ \t]*[*_`]*[ \t]*$/m
const VERDICT_CHANGES_LINE = /^[ \t]*[*_`]*[ \t]*VERDICT:[ \t]*changes-required[ \t]*[*_`]*[ \t]*$/m
export function verdictGateFailure(rawResult) {
  if (typeof rawResult !== "string") return "no-pass-line"
  if (VERDICT_CHANGES_LINE.test(rawResult)) return "changes-required"
  return VERDICT_PASS_LINE.test(rawResult) ? null : "no-pass-line"
}
```

- **拒签输出（逐字形）**：`[stripDesignTokenEcho(rawResult, designToken).trim(), 标记].filter(Boolean).join("\n\n")`——`passed: false`；槽零写 ∥ 实例保持（`run.open` 不动）∥ 零 `_engDesignReviewed`（修后重评）。标记（恒定——`reason` = `no-pass-line` ∥ `changes-required`；实现 = `VERDICT_GATE_MARK` 模板串）：

```text
裁定非通过——token 未签发 (review verdict is not pass — no design token was issued; reason: <no-pass-line|changes-required>; the echoed token was stripped)
```

- **接口面（改前→改后）**：`settleDesignReview(agent, run, designToken, rawResult, opts)` **签名零改**（行为收窄）；新导出 `verdictGateFailure(rawResult)`（新面）；`validateDesignToken` ∥ regex 族 ∥ `stripDesignTokenEcho` ∥ suffix 族 ∥ `_engDesignReviewed` 写点零改；re-export 面（`advisor-async.mjs:45`）零触；同步径（`agent-tools/advisor.mjs:261`）∥ 异步径（`advisor-settle.mjs:155`）共用本单点——零调用点改。
