**机制设计（要点与判定）**：
- **① 公共组件**：基座 = 原生 `<dialog>` + `showModal()`（平台承担模态语义——顶层渲染 ∥ 背景 inert ∥ ESC 缺省关闭（`cancel` 事件）∥ `::backdrop` 遮罩——MDN 实核）；本档只补壳与策略。API = `openModal({ title, body, footer, onClose })` ⇒ 句柄 `{ close(), root }`；**单例**（不叠加——开新先关旧）；关闭 = × ∥ Esc ∥ 句柄（**遮罩点击不关**——平台 `closerequest` 缺省，防误触丢表单）；关闭即弃草稿（沿语言切换草稿口径）；焦点 = 平台语义（打开入窗 ∥ 背景 inert ∥ 关闭还原——收口轮实走核验）；开窗期锁背景滚动（`body.modal-open`）。可测性 = 模块顶层零浏览器全局（node 可 import——API 形断言）。
- **② 成员弹窗**：入口 = 成员表行点击（`tr.row-clickable tabindex="0"`——Enter/Space 同开）+ 页首「新建成员」钮；现行操作全迁入（设额度 ∥ 重置密码 ∥ 逐 key 吊销）；保存/取消语义 = 编辑态（保存 ⇒ POST quota ⇒ 回查看态；取消/关闭 ⇒ 丢弃）；秘密面动作（新建 ∥ 重置）成功 ⇒ **关窗 + 页级一次性秘密区**（`ctx.showSecret`——「仅一次」语义不变）；幂等操作（额度 ∥ 吊销）成功 ⇒ 弹窗留驻 + 就地重渲。表列重排 = 展示名 ∥ 用户名 ∥ 角色 ∥ 额度 ∥ 已用 ∥ key 数（key 清单/操作两列收编入弹窗）。
