## 2. 设计档落点与理由

- **落点**：`docs/core/design/DOC-DISCIPLINE.md` **§3.23 条目 W**（行号坐标清单）· **§3.24 条目 X**（档名豁免单一判定面）；另在 §3.20 判据表后加一行**指向句**（判据面仍是两条，清单另住 §3.23）；§3 标题括注与档头枚举同步（D3）。
- **为什么不写进 §3.20**（可回答「为什么它不该跟闸判据并列」）：
  ① §3.20 的判据面是**闭集且计数在文**（「起步两条判据」——档头 ∥ 判据表两行 ∥ `AC-M8` 计数）：清单进去，那句「两条」当场失真，而闸的读者会把它读成第三判据；
  ② **消费方式不同**：判据产 verdict、带处置义务（当场修到零命中）；清单产读数、无处置义务（清账是另事）——同一节住两种消费方式，读者只能逐句分辨；
  ③ §3.21 条目 T 已占「行号引」这一族，但它判的是「越界 / 无主引」，**抽取的轴不同**（T 按起点 token 分形，本条按归属窗定位）——并进 T 会把一条判据与一份清点塞进同一条目。
- **条目号跳过 `V`**：`V1`–`V6` 已是 §2 的校验族编号（§3.23 首行已注明）。

## 3. 机制设计（四件必需项 + 抽取式）

- **判据句**（单源 = §3.23）：行号坐标 = 一个**档名**之后出现的 `:` 加数字；归属窗三形闭集 = 紧贴 ∥ 承名 ∥ 段落承名（取上一行**最后一个**档名）。三形是读数分类、不是判据分级。
- **抽取式（逐字）**：

```text
档名：/(?<![A-Za-z0-9_.\-\\/@])((?:[A-Za-z0-9_.\-]+\/)*[A-Za-z0-9_.\-]+\.(?:md|mjs|cjs|js|json|css|html|svg|yml|yaml|sh|ps1))(?![\w])/
坐标：/(?<![0-9:]):(\d+)(?:-(\d+))?(?![\w])/
```

- **① 它不阻断**：清单只在 `report` 分支被调用——`gate` 分支不调用采集器、不产出该字段 ⇒ 闸的 verdict ∥ 命中条数 ∥ `hits.total` **构造上**看不到清单。验收 = §5 A-DD37 ③（结构面 grep 调用点 + 读数面 DD-144 前后对比）。
- **② 无命中写「0 处」并带量法**：清单块**第一行**即量法（抽取式 ∥ 扫描域），无命中仍出「行号坐标 0 处」，块内不留空行。验收 = DD-143。
- **③ 误报怎么看**：每处给 `源档:行` + 原文片段（≤ 40 字）；读者按三问判——名字带不带扩展名 ∥ 数字是不是行号 ∥ 目标档在盘且行号 ≤ 该档行数（不成立 = 举例 / 死坐标）。两类固有歧义（同行多档名 ∥ 举例自带坐标）在 §3.23 登记，照列不判。
- **④ 与 #1968 的关系 = 本批接管判定面**：`CANON_OPERANDS` 在导出面上，`FILENAME_CLASSES` / `PLACEHOLDER_STEMS` 私有 ⇒ 兄弟脚本那条判定**不是判错，是没判**。改法 = 导出**谓词** `docNameExemption(basename)`（两张表保持私有），三处消费同一判定；`prompt-refs-check` 的 J1 / J3 命中也走它。
  **为什么这个形式不会分叉**：表不上导出面，消费方就没有第二处可以添加名字——新增一类豁免只能改谓词体一处，三面同轮继承（机械判据 = `export` 行零含两表名）。
- **验收落位**：`node scripts/prompt-refs-check.mjs` 现盘 **10 条 / exit 1**（本席实读 2026-11-01：提示词面 70 档 · 代码面 476 档）⇒ 改后 **4 条**，四条逐字列在 §3.24 围栏内（`:142` 同行两处各计一条）。那 4 条本批**不修**，收口后仍 exit 1——如实状态，非回归。
- **两个面并列（同一量法）**：正文面（围栏块 ∥ 可执行行跳过）· 围栏内 · 合计，三数并列打印；先例 = §3.22 U-3 的两读并列。

## 6. 关键决策（含被否方案）

1. **落点 = 新开条目，不进 §3.20**（理由三条见 §2）。**被否**：写进 §3.20 判据表下（会让「两条判据」失真、两种消费方式混住）。
2. **抽取式不复用条目 T**：T 的 Ⅲ 形要求坐标紧贴档名、Ⅰ 形只认回指词，② ③ 与跨行归属整块丢——F11 三形里有两种报不出。**被否**：把 T 的抽取式加一个「上一行」窗口（等于两处定义同族而口径不同）。
3. **零阻断靠结构而非纪律**：清单在 gate 分支**不存在**（不计算、无字段），不是「算出来但不影响 verdict」。**被否**：算出来标「不参与」——一份存在但被声明无用的数，读者迟早会拿它当判据。
4. **两读并列（正文面 ∥ 围栏内）**：围栏里也有存量坐标（清账要看见），围栏同时是举例的家（读者要分清）。**被否**：只报正文面（漏存量）∥ 只报全文面（举例混进读数）。
5. **豁免 = 导出谓词、表保持私有**（§3.24）：导出表会重演今天的分叉；导出判定让「第二处添加」无处可加。
6. **#1968 处置 = 接管判定面、不接管判据面**：`prompt-refs-check` 的 J1/J2/J3 三式与域零改，只把「哪些名字不算档」改成共用；4 条真违规归清账批。**被否**：把它并进 `doc_check`（两套判据、两套域，合并=第二权威源）。
