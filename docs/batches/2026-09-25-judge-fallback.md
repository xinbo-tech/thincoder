### 2.2 机制设计（正本 = 设计档 §2.10.1 / §2.10.3 / §2.10.4 / §2.14；本节只给口径与边界）

1. **级链（逐位）**：`[原位槽, 池第 1 项, … 池第 6 项]`——任一级得有效判（`pass` / `fail`）即止；级链穷尽 ⇒ 该位 `error`（逐级留证）。级内：严格解析失败 ⇒ 该级放大预算重试一次（`maxTokens × 2` ≤ 8192）；传输面失败（超时 / HTTP）⇒ 不重试同模型、直接进下一级（核已含 HTTP 级重试；换模型即重试路径）。
2. **合成（级联后）**：A / B 同向 ⇒ `unanimous`；相异 ⇒ C 触发（C 同样级联）⇒ 多数派 `arbitrated`；恰 1 位有效 ⇒ `single`（单判定判——旧「禁单判回退」已废）；零有效判 / 分歧未决 ⇒ `none` + `error`（物理边界）。
3. **身份约束（两条同源）**：静态 = 池内两两 `model` 字面不同 ∧ ∉ {A, B, C}（装载即拒）；运行期 = 逐级取用时跳过本 run 已占用（原位三槽 + 已选定替代位）——**替代 ≠ 失败位模型 ∧ ≠ 存活判官 ∧ ≠ 彼此**。同模型双判无冗余纪律的运行期延伸。
