# 桌面端（DESKTOP）· 需求

> 板块 = **桌面端产品定性**——ThinCoder 第三个接入端的定位、功能范围与边界。
> 本档 = 桌面端产品级定性的需求层权威；产品族定性（三端关系）与跨产品共享契约见 `docs/core/requirements/PROJECT.md`（§1 / §3）。
> 核机制面（agent 主循环 / 工具 / 记忆 / 配置）**只住核**，本档不重述（单一权威源）。
> 建档：2026-09-25（用户裁定「增加桌面端」；同日收敛 = 单项目 + 项目内多会话 · 三平台从第一天 · 宿主 = Electron · 前端自持且零框架 · 文件视图与编辑器暂缓）。
> 本档坐标 = as-of 2026-09-25 实核（仓根 = `thincoder/`）。

## 1. 模块目标

给不想、不能用 VS Code 的人一个**独立桌面入口**：同一个 agent、同一份配置与会话、比终端更宽的会话与活动视图——单项目多会话，没有终端也能配好并开始干活。

## 2. 定位

| 项 | 内容 |
|---|---|
| 品类 | 通用 AI 编码智能体的**第三个接入端**（形态 = 桌面应用）——不改品类定性（`docs/core/requirements/PROJECT.md` §5.1） |
| 目标用户 | ① 不装 VS Code 的开发者；② 需要比 TUI 更宽的会话 / 活动 / 后台视图的人；③ 不熟命令行的使用者（首启无终端可完成配置） |
| 与另两端 | 同级独立产品、互不依赖；读写同一份 `~/.thincoder/config.json` 与 `~/.thincoder/sessions/`（承 `docs/core/requirements/PROJECT.md` §3 的 C1 / C2 契约） |
| 项目模型 | **单项目**：一次服务一个工作目录（会话按 cwd 寻址）；多项目并行 = 开多个实例（核已有跨实例协作面） |
| 宿主 | Electron——桌面运行时按**宿主平台**口径（与扩展端把 VS Code API 当宿主同支）；Electron 随发行物分发，其体积 / 供应链 / 三平台打包链成本落本端发行面 |
| 前端 | **零框架手写，纯 DOM + 浏览器原生**；**与扩展端共用宿主无关渲染核**（2026-09-27 用户裁定——核落点 / 边界 = 设计轮定形） |
| 壳装配 | 本端独有（核装配的第三份——CLI ∥ 扩展端各一份）；是否抽共享层为独立议题，不并入本程序 |

## 3. 界面形态

> 本节形态 = 父侧提案，2026-09-25 用户认可后落档；控件 / 样式 / 断点等细部留给设计轮。

### 3.1 主界面 = 会话面板（单面板 · VSC 模型）

**会话模型裁定（2026-09-28 19:04 裁）**：多会话标签模型**裁撤**——会话面 ⇒ **VSC 单面板模型**（会话切换 ∕ 新建 ∕ 列表按 VSC 会话面逐元素移植，不新造）；标签条 ∕ 标签存储 ∕ 关闭确认 ∕ 页随动 ∕ 每键一槽（`session:<n>`）**随之下线**。
**左列裁撤（19:0x 续裁「整个左侧栏都废掉」）**：会话切换 = **VSC 同款下拉选会话**（原左侧会话列表 ∕ 新建入口并此）；**整个左侧栏（会话列表 ∕ 项目目录 ∕ 项目级信息）随裁废**——VSC 无对位面不新造。
本节含「标签」·「左列」各句以本条为准（实施 = 对齐批会话轮；台账 #528）。

```
┌────────────────────────────────────────────┬────────────────────┐
│ 会话面板（单面板 · VSC 模型）                 │ 本会话活动池        │
│ 会话控制：下拉选会话 + 新建（VSC 形）          │  ▸ 子代理块（角色 · 模型│
│ 会话头：provider / 模型 / 档位               │    + 状态）        │
│ 对话流：流式 token · 推理块 · 工具卡          │  ▸ advisor/consult │
│ 审批卡（流内）· 错误卡                        │  ▸ 队列            │
│ 输入框（Enter 发送 / Shift+Enter）           │  ▸ 待审批（计数 +  │
│                                            │    操作区）        │
│                                            │ 随活动会话 · 可折叠 │
└────────────────────────────────────────────┴────────────────────┘
状态栏：模式四（AUTO / PLAN / ADVISOR / ENG · 真态时）行首 · 上下文占用（活动会话） · 跨会话待审批提示（形随对齐批）
```

- **会话控制（面板内 · VSC 形）**：下拉选会话（**全部**会话 = 历史，运行中 / 待审批带位标；与 CLI / 扩展端是**同一份**——共享会话目录，点开即续）+ 新建入口；左列裁撤后无第二入口（2026-09-28 裁）。
- **会话面板（单面板 · VSC 模型）**：会话头 + 对话流 + **右侧本会话活动池**（两栏并列；池可折叠——折叠后对话流得全宽）。
- **会话头（每会话）**：provider / 模型 / 推理档位——**会话级可改三值**（随会话槽持久化，切会话即随之切换，与 CLI / 扩展端同一份槽；**推理档位槽字段 = `effort`**——本节要求会话级、核尚未有 ⇒ 设计落点 = `docs/core/design/SESSION.md` §6.21 ✓）。
  **模式四位（AUTO / PLAN / ADVISOR / ENG）住状态行行首**（与 CLI 同段位——「屏面为准」重审裁定，2026-09-28；槽字段 = `autoApprove` / `planMode` / `advisor.guard` / `engineering`——真态时在场）。
  注意区分：**工程模式状态**是会话级（住会话槽），但它 **ON 方向的准入判据**要读项目根的 manifest 档——两者不同层，不得混为一谈。
- 会话控制住面板内（下拉 + 新建——VSC 形；位置与控件逐元素表 = 对齐批；第二入口不存在）。
- **对话流**：消息流（流式 token · 推理块）· 工具卡（名称 + 参数摘要 + 状态 + 可展开结果，**含改动摘要** = 文件 + 增删行数；**diff 预览按对齐办**——VSC 同款行级 diff〔2026-09-28 收正：原「不做 diff」系流程自划 · 非用户裁定〕）· 错误卡 · 审批卡（流内嵌）· 输入框。
- **活动池（每会话一份 · 会话视图内靠右）**：子代理活动块（粒度 = 角色 · 模型 · 用时 · 回合 + 状态词；**内容回显 = 核件 tail-3 / 展开**〔2026-09-28 收正〕）· advisor / consult · 队列 · 待审批（计数 + 操作区）。**位置与「全局右栏」同形，差别只在归属**：每会话一份、随活动会话切换（全局常驻池不存在——见 §3.4）。
- **状态栏**：**模式四位行首在场（真态时）** · 活动会话的上下文占用（实时读数）· **跨会话告警**（他会话待审批 ∕ 运行——不静默等待；形随 VSC 对齐批）。**同一事实只出现一处**：三值配置项住会话头、模式四位住状态行行首（2026-09-28 屏面为准重审——两处各有其位，不得重复呈现）。

### 3.2 一回合的时序（可感行为）

1. 用户发送 ⇒ 对话流流式推进，本会话活动池出现活动块；
2. 需要用户点头时：**对话流内嵌审批卡** + **本会话活动池的待审批计数 +1** + **告警位显形（形随 VSC 对齐批）**；若你在别处，**状态栏给提示**（不静默等待）；
3. 子代理在活动池活动（粒度 = 角色 · 模型 · 用时 · 回合 + 状态词；**内容回显 = 核件 tail-3 / 展开**）· 完成后**归档入流**（D3 / D20——2026-09-28 收正）；**并发可见性 = 不翻页可见谁在跑 ∕ 谁在等**（载体形随 VSC 对齐批）；
4. 回合收尾：结果进对话流，状态栏上下文占用更新。

### 3.3 首启（无终端可完成）

选 provider → 填 key（真调一次校验）→ 选工作目录 → 可用。
若 `~/.thincoder/config.json` 已存在（CLI 或扩展端已配）⇒ **跳过向导**，直接进主界面。

### 3.4 不出现在界面上的

 文件树 · 编辑器 · 内置 diff · 终端面板 · 常驻多项目面板 · **常驻全局活动栏**（活动池随会话——§3.1）——均无；前两项 = 暂缓项（2026-09-25 收敛登记 · 出处随重核）；内置 diff / 终端面板 / 常驻多项目面板 = §5.2 边界；常驻全局活动栏 = 形态裁定。

### 3.5 待设计形（本轮不锁）

- 同项目多会话**并行跑**时，活动池的池 / 队列分层显示形态；
- 跨会话告警位的精确形（随 VSC 对齐批）；
- 会话行**标注来源端**（该会话由 CLI / 扩展端 / 桌面端所建）——核侧「**创建端**」字段**已落地**（`listSlots[].createdBy` · 台账 #372 · 2026-09-25）；字段缺失（老槽）时**退化为不标注**（**不猜测**——「当前占用端」与「创建端」不同义，不得冒充）。

## 5. 边界

### 5.1 暂缓（本轮不做，登记为后续议题）

- **文件视图与编辑器**（编辑 / 保存 / 内置 diff 编辑器本体）——2026-09-25 收敛登记为暂缓（**出处随「对齐」重核**；是否做属产品范围议题）；**「打开文件」已出暂缓**——文件链接点开按对齐办（2026-09-28 收正）；
- **常驻多项目面板 / 项目切换器**——多项目并行以多实例满足。

### 5.2 不做

- 云服务 / 托管平台、模型 / 推理服务、工作流引擎；
- 复制核机制（机制只住核）；另立会话 / 配置存储格式（照既有契约）；
- 既有 ACP 面之外的新协议面；
- 通用编辑器 / IDE（`docs/core/requirements/PROJECT.md` §5.3——桌面端同受此限）。
