## 1. 总体目标

VSC 部分的**活档内容**必须在基准层 `docs/` 内有家——`thincoder-vscode/docs/**` 自此逐档降格为**参照历史**（保留 ≠ 维护）。

当前状态是「一核两壳合并、文档只有产品树有」：VSC 端 84 档板块档全部住在产品树，基准层 `docs/` 里 VSC 部分为**空**。
不把 VSC 部分建起来，「开始整文档」时 VSC 侧永远没有可写的落点，每次都要现场判归属——这正是 `docs/core/design/DOC-SYSTEM.md` §1 点名的「归属无判据」病。

**为谁解决什么问题**：为**本仓维护者与设计评审者**解决「VSC 部分的文档住哪里、哪份是权威、旧档与新档什么关系」——
达成后：写 VSC 文档有确定落点（`docs/vsc/` 或 `docs/core/`，按 P1–P5 判）；产品树旧档的权威性有明确定性（参照历史）；机检射程覆盖新目录（无「无守卫窗口」）。

> 格式 = 作为一个 [角色]，我想要 [功能]，以便 [目的]。每条带**判定句**（验收语义——可机判/可复核）。

| # | 用户故事 | 判定句（验收语义） |
|---|---|---|
| **F-M1** | 作为**本仓维护者**，我想要 VSC 端 `docs/{design,requirements}/**` 的**逐档清点**（活/历史二分 + 落点），以便知道哪份该迁、哪份留原地 | 实点表逐档一行、行数 = 实核值；二分表四行 disjoint 加总 = 实点数（84）；小计与实点闭合（不符 ⇒ 差在哪逐条明写） |
| **F-M2** | 作为**维护者**，我想要「**活档 ⇒ 迁 · 历史 ⇒ 就地留**」的判据可复核，以便不必每次现场再判 | 逐档带**依据列**（① `docs/core/` 是否已有同话题活档 → 给路径 ② 是否已被现行设计取代 → 给对照点 ③ 是否只描述核内已单源化机制）；判不准者**单列「待核」**（两种读法 + 依据，不静默归类） |
| **F-M3** | 作为**维护者**，我想要**第一批活档当场迁完**（不是只出统计），以便规划与执行同轮见效 | 本批产出 ≥1 档基准层**活档**（旧档一字不改）；逐档报「旧档 → 落点」 |
| **F-M4** | 作为**评审者**，我想要迁移后的档**不带批次材料**（状态行 / 变更流水 / 一次性交付材料），以便读的是**现行机制**而非某批的施工记录 | 落点档无状态行、无逐批流水；一次性材料与 (d) 类旧结构逐项登记入「不并项与历史沿革」节 |
| **F-M5** | 作为**维护者**，我想要**被迁档内的坐标改写为现状路径**，以便断言可核 | 每条 `文件:行` 断言按现状路径实核（迁移期发现旧档坐标漂移 ⇒ 按现状改写并在报告列出） |
| **F-M6** | 作为**维护者**，我想要**新建目录同批进机检射程**，以便新目录不出现「无守卫窗口 + 假绿」 | 新建目录同批写入两扫描器射程常量；改后实跑并报读数（改前 / 改后档数） |

## 3. 非功能性标准

| # | 维度 | 标准 | 度量方式（判定句） |
|---|---|---|---|
| **N-M1** | 可机判 | 迁移结论不用自然语言描述代替判据——每条分类可回指判据句（P1–P5 / ①②③ 依据） | 二分表依据列逐行非空；「待核」行含两种读法 |
| **N-M2** | 零悬空 | 落点档在内的文档锚域**悬空 = 0**（阈值 0，不得入基线） | `node scripts/doc-anchors.mjs` 根域汇总「悬空 0」 |
| **N-M3** | 格式合规 | 新增档无 >300 字符单行（表格行豁免）；>300 行给拆分规划、>500 行必拆 | `node scripts/check-doc-width.mjs`「无 >300 字符单行」+ 各档行数自测 |
| **N-M4** | 射程完整 | 新建目录被两扫描器覆盖（`SCAN_DIRS` · `V5_SCAN_DIRS`），不得只建目录不入射程 | 两常量含新目录；改后门禁实跑读数（改前 / 改后档数）对照 |
| **N-M5** | 可回退 | 每批改动单笔可 revert；不 commit | `git status` 改动集 = 声明的写域（`docs/vsc/**` + `scripts/**` 射程枚举） |
| **N-M6** | 只读边界 | VSC 产品树 `thincoder-vscode/**` 一字不改（含注释）；核树 / CLI 树 / 台账 / 提示词零写 | `git status` 无 `thincoder-vscode/**` 条目 |
